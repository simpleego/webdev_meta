카카오 맵 API를 사용해서 현재 위치를 표시하는 간단한 지도 프로그램을 만들어드리겠습니다.카카오 맵을 이용한 현재 위치 표시 프로그램을 만들어드렸습니다. 이 코드를 사용하기 위해서는 몇 가지 설정이 필요합니다:

**사용하기 전 필요한 설정:**

1. **카카오 개발자 계정 등록**
   - https://developers.kakao.com 에서 개발자 계정 생성
   - 새 애플리케이션 등록

2. **JavaScript 키 발급**
   - 애플리케이션 설정에서 JavaScript 키 복사
   - 코드의 `YOUR_APP_KEY` 부분을 실제 키로 교체

3. **플랫폼 등록**
   - 웹 플랫폼 등록 (도메인 또는 localhost)

**주요 기능:**
- 현재 위치 찾기 버튼 클릭 시 GPS로 위치 획득
- 지도 중심이 현재 위치로 이동
- 마커로 현재 위치 표시
- 위도, 경도 정보 표시
- 좌표를 주소로 변환하여 표시

**사용법:**
1. 카카오 API 키를 설정한 후 HTML 파일로 저장
2. 웹 브라우저에서 열기
3. "현재 위치 찾기" 버튼 클릭
4. 브라우저에서 위치 권한 허용

위치 정보 사용 권한을 허용해야 정상적으로 동작합니다!
