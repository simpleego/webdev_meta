## 📚 2주차 커리큘럼: Spring Boot 구조 이해 + Hello World

### 🎯 학습 목표
- Spring Boot의 프로젝트 구조와 주요 구성 요소 이해
- 컨트롤러를 통해 웹 요청 처리 흐름 익히기
- 브라우저에 “Hello World” 출력하는 기본 웹 애플리케이션 구현

---

### 🗓️ 수업 구성 (총 2~3시간 분량)

#### 1. Spring Boot 개요 (30분)
- Spring Framework vs Spring Boot 차이점
- 자동 설정(Auto Configuration)과 내장 톰캣의 역할
- Starter 의존성의 개념
- 프로젝트 구조 설명
  ```
  src/
   └─ main/
       ├─ java/ → 자바 소스 코드
       └─ resources/ → 설정 파일, 템플릿, 정적 리소스
  ```

#### 2. 실습: Hello World 프로젝트 만들기 (1시간)
- IntelliJ에서 Spring Initializr로 새 프로젝트 생성
  - Project: Maven
  - Language: Java
  - Spring Boot: 3.x
  - Dependencies: Spring Web
- 기본 디렉토리 구조 확인
- `HelloController` 클래스 생성
```java
package com.example.helloworld;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.ResponseBody;

@Controller
public class HelloController {

    @GetMapping("/")
    @ResponseBody
    public String hello() {
        return "Hello World!";
    }
}
```
- `DemoApplication.java` 실행
- 브라우저에서 `http://localhost:8080` 접속 → “Hello World!” 확인

#### 3. 구조 분석 및 흐름 설명 (30분)
- `@Controller`, `@GetMapping`, `@ResponseBody`의 역할
- 요청 → DispatcherServlet → Controller → 응답 흐름
- application.properties의 기본 설정

#### 4. Q&A + 실습 확장 아이디어 (30분)
- URL 경로 추가 실습 (`/greeting`, `/about` 등)
- HTML 없이 텍스트 응답과의 차이점 설명
- 다음 주차 예고: Thymeleaf를 활용한 화면 구성
