# 2단계 :m 객체와 리스트 모델화 및 뷰처리
> 서버에서 전달된 **리스트(List)** 또는 **객체(Object)**를 Thymeleaf를 통해 화면에 출력하는 예제

---

## 🧪 예제 1: 객체(Object) 출력하기

### 📁 구조
```
src/
 └─ main/
     ├─ java/com/example/demo/
     │   ├─ controller/UserController.java
     │   └─ model/User.java
     └─ resources/templates/user.html
```

### 1️⃣ 모델 클래스 생성

```java
package com.example.demo.model;

public class User {
    private String name;
    private int age;
    private String email;

    // 생성자
    public User(String name, int age, String email) {
        this.name = name;
        this.age = age;
        this.email = email;
    }

    // Getter
    public String getName() { return name; }
    public int getAge() { return age; }
    public String getEmail() { return email; }
}
```

### 2️⃣ 컨트롤러 작성

```java
package com.example.demo.controller;

import com.example.demo.model.User;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class UserController {

    @GetMapping("/user")
    public String user(Model model) {
        User user = new User("홍길동", 25, "hong@example.com");
        model.addAttribute("user", user);
        return "user";
    }
}
```

### 3️⃣ Thymeleaf 템플릿 (`user.html`)

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>사용자 정보</title>
</head>
<body>
    <h2>사용자 정보</h2>
    <p>이름: <span th:text="${user.name}">이름</span></p>
    <p>나이: <span th:text="${user.age}">나이</span></p>
    <p>이메일: <span th:text="${user.email}">이메일</span></p>
</body>
</html>
```

## 🧪 예제 2: 리스트(List) 출력하기

### 📁 구조
```
src/
 └─ main/
     ├─ java/com/example/demo/
     │   ├─ controller/UserListController.java
     │   └─ model/User.java
     └─ resources/templates/userList.html
```

### 1️⃣ 컨트롤러 작성

```java
package com.example.demo.controller;

import com.example.demo.model.User;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

import java.util.List;

@Controller
public class UserListController {

    @GetMapping("/users")
    public String users(Model model) {
        List<User> userList = List.of(
            new User("홍길동", 25, "hong@example.com"),
            new User("김철수", 30, "kim@example.com"),
            new User("이영희", 22, "lee@example.com")
        );
        model.addAttribute("users", userList);
        return "userList";
    }
}
```

### 2️⃣ Thymeleaf 템플릿 (`userList.html`)

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>사용자 목록</title>
</head>
<body>
    <h2>사용자 목록</h2>
    <table border="1">
        <tr>
            <th>이름</th>
            <th>나이</th>
            <th>이메일</th>
        </tr>
        <tr th:each="user : ${users}">
            <td th:text="${user.name}">이름</td>
            <td th:text="${user.age}">나이</td>
            <td th:text="${user.email}">이메일</td>
        </tr>
    </table>
</body>
</html>
```

---

## 💡 학습 포인트

- `th:each`는 반복문 역할을 하며 리스트를 순회
- `${user.name}`처럼 객체의 속성을 직접 참조 가능
- 추가 기능 구현 문제
  -  **사용자 추가/삭제 기능을 구현**
