# JSP를 View로 사용하는 Spring Framework(스프링 프레임워크) 프로젝트를 설정하는 방법
>  **Spring Initializr**를 활용

-----

### \#\# 1단계: Spring Initializr로 프로젝트 생성 ⚙️

IntelliJ의 내장 기능을 이용해 기본적인 스프링 부트 프로젝트 구조를 만듭니다.

1.  **IntelliJ 실행 후 `File > New > Project...`를 선택합니다.**

2.  **`New Project` 창에서 왼쪽 메뉴의 `Spring Initializr`를 선택합니다.**

      * **Name**: 프로젝트 이름을 입력합니다. (예: `jsp-project`)
      * **Location**: 프로젝트가 저장될 위치를 지정합니다.
      * **Type**: `Maven` 또는 `Gradle`을 선택합니다. (일반적으로 Maven이 많이 사용됩니다.)
      * **Group**: 보통 회사의 도메인을 역순으로 적습니다. (예: `com.example`)
      * **Artifact**: 프로젝트의 고유 이름입니다. (보통 Name과 동일하게 자동 설정됩니다.)
      * **Package name**: Group과 Artifact를 조합한 패키지 경로가 자동으로 생성됩니다.
      * **JDK**: 설치된 JDK 버전을 선택합니다. (Java 17 또는 21 권장)
      * **Packaging**: **매우 중요합니다\!** JSP를 사용하려면 반드시 \*\*`War`\*\*를 선택해야 합니다.
          * `Jar`: 내장 톰캣(Tomcat)을 포함하여 단독으로 실행되는 파일입니다.
          * `War`: 외부 서블릿 컨테이너(Tomcat 등)에 배포되는 웹 애플리케이션 아카이브 파일입니다. JSP는 이 방식을 사용해야 정상적으로 동작합니다.

3.  **`Next`를 눌러 의존성을 추가합니다.**

      * **Spring Web**: Spring MVC를 사용하여 웹 애플리케이션을 구축하는 데 필수적입니다.
      * **Spring Boot DevTools**: 코드 변경 시 자동으로 서버가 재시작되어 개발 편의성을 높여줍니다. (선택 사항이지만 강력히 추천)

    **`Create`** 버튼을 눌러 프로젝트를 생성합니다.

-----

### \#\# 2단계: JSP 사용을 위한 설정 📝

프로젝트가 생성된 후, JSP를 View로 사용하기 위한 몇 가지 추가 설정이 필요합니다.

1.  **`pom.xml`에 JSP 컴파일 의존성 추가**

    Spring Boot는 기본적으로 JSP를 지원하지 않으므로, JSP 파일을 서블릿으로 컴파일해주는 `tomcat-embed-jasper` 의존성을 추가해야 합니다. `pom.xml` 파일을 열고 `<dependencies>` 태그 안에 아래 코드를 추가하세요.

    ```xml
    <dependency>
        <groupId>org.apache.tomcat.embed</groupId>
        <artifactId>tomcat-embed-jasper</artifactId>
        <scope>provided</scope>
    </dependency>
    ```

    > **💡 Tip:** `<scope>provided</scope>`는 이 라이브러리가 배포될 외부 톰캣에 이미 포함되어 있으므로, 최종 WAR 파일에는 포함하지 말라는 의미입니다. 하지만 내장 톰캣으로 개발할 때는 필요하기 때문에 추가합니다.

2.  **`application.properties` 설정**

    Spring이 JSP 파일의 위치와 확장자를 알 수 있도록 경로를 설정해야 합니다. `src/main/resources/application.properties` 파일을 열고 아래 내용을 추가하세요.

    ```properties
    # JSP View Resolver 설정
    spring.mvc.view.prefix=/WEB-INF/views/
    spring.mvc.view.suffix=.jsp
    ```

      * `prefix`: JSP 파일들이 위치할 기본 폴더 경로입니다. 보안을 위해 보통 `/WEB-INF/` 하위에 둡니다.
      * `suffix`: JSP 파일의 확장자입니다.

3.  **JSP 파일을 저장할 폴더 생성**

    `application.properties`에 설정한 경로(`prefix`)대로 폴더를 만들어야 합니다.

      * `src/main` 폴더 아래에 `webapp` 폴더를 생성합니다.
      * `webapp` 폴더 아래에 `WEB-INF` 폴더를 생성합니다.
      * `WEB-INF` 폴더 아래에 `views` 폴더를 생성합니다.

    최종 경로는 `src/main/webapp/WEB-INF/views/` 가 됩니다.

### \#\# 3단계: 간단한 예제 작성 ✏️

이제 컨트롤러와 JSP 파일을 만들어 간단한 "Hello, World\!"를 출력해 보겠습니다.

1.  **Controller 클래스 생성**

    `src/main/java/com/example/jspproject` 패키지 아래에 `controller` 라는 새 패키지를 만듭니다. 그리고 그 안에 `HelloController` 클래스를 생성합니다.

    ```java
    package com.example.jspproject.controller;

    import org.springframework.stereotype.Controller;
    import org.springframework.ui.Model;
    import org.springframework.web.bind.annotation.GetMapping;

    @Controller
    public class HelloController {

        @GetMapping("/") // 루트 URL ("/") 요청을 처리합니다.
        public String hello(Model model) {
            // Model 객체를 사용해 View에 데이터를 전달합니다.
            model.addAttribute("message", "Hello, Spring with JSP! 👋");

            // "hello"라는 문자열을 반환합니다.
            // ViewResolver가 prefix와 suffix를 조합하여
            // /WEB-INF/views/hello.jsp 파일을 찾아 렌더링합니다.
            return "hello";
        }
    }
    ```

2.  **JSP View 파일 생성**

    앞서 만든 `src/main/webapp/WEB-INF/views/` 폴더 안에 `hello.jsp` 파일을 생성하고 아래와 같이 작성합니다.

    ```jsp
    <%@ page contentType="text/html;charset=UTF-8" language="java" %>
    <html>
    <head>
        <title>Spring JSP Example</title>
    </head>
    <body>
        <h1>JSP View Page</h1>
        <p>${message}</p> <%-- Controller에서 전달한 'message' 데이터를 출력합니다. --%>
    </body>
    </html>
    ```

### \#\# 4단계: 애플리케이션 실행 및 확인 🚀

1.  IntelliJ의 프로젝트 탐색기에서 `src/main/java` 아래의 메인 애플리케이션 파일(예: `JspProjectApplication.java`)을 찾습니다.
2.  해당 파일을 마우스 오른쪽 버튼으로 클릭하고 **`Run 'JspProjectApplication'`** 을 선택하여 서버를 실행합니다.
3.  콘솔 창에 `Tomcat started on port(s): 8080`과 같은 메시지가 나타나면 서버가 정상적으로 실행된 것입니다.
4.  웹 브라우저를 열고 주소창에 `http://localhost:8080` 을 입력합니다.
5.  화면에 "Hello, Spring with JSP\! 👋" 메시지가 보이면 성공적으로 프로젝트가 구성된 것입니다.

### \#\# 핵심 요약

  * **Packaging**: 프로젝트 생성 시 반드시 \*\*`War`\*\*로 설정해야 합니다.
  * **의존성**: `Spring Web`은 필수이며, JSP 컴파일을 위해 `pom.xml`에 \*\*`tomcat-embed-jasper`\*\*를 추가해야 합니다.
  * **설정**: `application.properties`에 \*\*`spring.mvc.view.prefix`\*\*와 \*\*`spring.mvc.view.suffix`\*\*를 설정하여 JSP 파일의 위치를 알려줘야 합니다.
  * **폴더 구조**: JSP 파일은 `src/main/webapp/WEB-INF/views/` 경로에 위치시킵니다.

이 단계를 따라 하시면 IntelliJ에서 JSP를 사용하는 스프링 프로젝트를 성공적으로 구성하실 수 있습니다.
