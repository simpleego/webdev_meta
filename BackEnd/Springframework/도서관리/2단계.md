## 🧩 전체 아키텍처 확장 개요

| 기능 영역 | 설명 |
|-----------|------|
| Customer | 회원가입, 로그인, 회원정보 수정, 탈퇴 |
| Order | 도서 주문, 주문내역 조회, 주문 취소 |
| Admin | 도서/회원/주문 관리, 통계 대시보드 |
| REST API | JSON 기반 API 제공 (도서, 주문, 회원 등) |

## 🌐 REST API 확장

### 📁 패키지 구조
```
com.example.bookstore.api
```

### 📄 주요 클래스
- `BookApiController.java`
- `CustomerApiController.java`
- `OrderApiController.java`

### 📄 예시: Book API

```java
@RestController
@RequestMapping("/api/books")
public class BookApiController {

    @Autowired
    private BookService bookService;

    @GetMapping
    public List<Book> getAllBooks() {
        return bookService.findAll();
    }

    @PostMapping
    public ResponseEntity<?> createBook(@RequestBody Book book) {
        bookService.save(book);
        return ResponseEntity.ok().build();
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<?> deleteBook(@PathVariable int id) {
        bookService.delete(id);
        return ResponseEntity.ok().build();
    }
}
```

### 📦 API 기능 요약

| 엔드포인트 | 설명 |
|------------|------|
| `GET /api/books` | 도서 목록 조회 |
| `POST /api/books` | 도서 등록 |
| `DELETE /api/books/{id}` | 도서 삭제 |
| `GET /api/customers` | 회원 목록 조회 |
| `POST /api/orders` | 주문 생성 |
| `GET /api/orders/{id}` | 주문 상세 조회 |
