# 시각화 차트
> 관리자 페이지에 통계 시각화를 추가하면 시스템이 훨씬 더 전문적이고 인사이트 중심
> **Svelte + Chart.js**를 활용해 도서관리 시스템의 통계를 시각화하는 방법
> 월별 주문량, 인기 도서, 고객 증가 추이 등을 시각적으로 표현
---

## 📊 통계 시각화 구성 개요

| 시각화 항목       | 설명                                      |
|------------------|-------------------------------------------|
| 월별 주문량       | 월별 주문 수량을 막대그래프로 표시        |
| 인기 도서 TOP5   | 가장 많이 주문된 도서 순위                |
| 고객 증가 추이    | 월별 신규 가입자 수                       |

---

## 🛠️ 개발 환경 설정

### 1️⃣ Chart.js 설치

```bash
npm install chart.js
```

### 2️⃣ Svelte용 Chart 컴포넌트 생성

```svelte
<!-- src/components/BarChart.svelte -->
<script>
  import { onMount } from 'svelte';
  import Chart from 'chart.js/auto';

  export let labels = [];
  export let data = [];
  let canvas;

  onMount(() => {
    new Chart(canvas, {
      type: 'bar',
      data: {
        labels,
        datasets: [{
          label: '월별 주문량',
          data,
          backgroundColor: '#4e79a7'
        }]
      },
      options: {
        responsive: true,
        plugins: {
          legend: { display: false },
          title: { display: true, text: '📦 월별 주문 통계' }
        }
      }
    });
  });
</script>

<canvas bind:this={canvas}></canvas>
```

## 📦 관리자 통계 페이지 (AdminStats.svelte)

```svelte
<script>
  import BarChart from '../components/BarChart.svelte';
  import { onMount } from 'svelte';
  import axios from 'axios';

  let labels = [];
  let data = [];

  onMount(async () => {
    const res = await axios.get('/api/admin/stats/orders/monthly');
    labels = res.data.map(item => item.month);
    data = res.data.map(item => item.count);
  });
</script>

<h2>📊 관리자 통계</h2>
<BarChart {labels} {data} />
```

## 🌐 백엔드 API 예시 (Spring Boot)

```java
@GetMapping("/admin/stats/orders/monthly")
public List<Map<String, Object>> getMonthlyOrderStats() {
    String sql = """
        SELECT DATE_FORMAT(order_date, '%Y-%m') AS month, COUNT(*) AS count
        FROM orders
        GROUP BY month
        ORDER BY month
    """;
    return jdbcTemplate.queryForList(sql);
}
```

## 🔥 인기 도서 TOP5 차트 예시

- Chart.js의 `doughnut` 또는 `horizontalBar` 타입 사용
- API: `/api/admin/stats/books/top`

```sql
SELECT b.bookname, COUNT(*) AS count
FROM orders o
JOIN book b ON o.book_id = b.id
GROUP BY b.bookname
ORDER BY count DESC
LIMIT 5;
```
