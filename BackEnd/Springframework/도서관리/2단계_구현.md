# 2단계 구현 
> **Customer**, **Order**, **Admin**, **REST API**를 실제로 구현
> Spring MVC + JSP 기반으로 구성되며, 필요한 클래스, URL 매핑, DB 테이블, JSP 화면

---

## 👤 Customer (회원 기능)

### 1️⃣ DB 테이블 생성
```sql
CREATE TABLE customer (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(100) NOT NULL,
    name VARCHAR(100),
    email VARCHAR(100),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2️⃣ DTO 클래스
```java
public class Customer {
    private int id;
    private String username;
    private String password;
    private String name;
    private String email;
}
```

### 3️⃣ Repository
```java
public class CustomerRepository {
    @Autowired JdbcTemplate jdbc;

    public void save(Customer c) { /* INSERT SQL */ }
    public Customer findByUsername(String username) { /* SELECT SQL */ }
}
```

### 4️⃣ Service
```java
public class CustomerService {
    public boolean login(String username, String password) { /* 인증 로직 */ }
    public void register(Customer c) { /* 회원가입 */ }
}
```

### 5️⃣ Controller
```java
@Controller
@RequestMapping("/customer")
public class CustomerController {
    @GetMapping("/register") public String showForm() { return "customer/register"; }
    @PostMapping("/register") public String register(...) { ... }
    @GetMapping("/login") public String loginForm() { return "customer/login"; }
    @PostMapping("/login") public String login(...) { ... }
}
```

### 6️⃣ JSP 화면
- `/WEB-INF/views/customer/register.jsp`
- `/WEB-INF/views/customer/login.jsp`

## 📦 Order (주문 기능)

### 1️⃣ DB 테이블 생성
```sql
CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    customer_id INT,
    book_id INT,
    quantity INT,
    status VARCHAR(20),
    order_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2️⃣ DTO 클래스
```java
public class Order {
    private int id;
    private int customerId;
    private int bookId;
    private int quantity;
    private String status;
}
```

### 3️⃣ Repository
```java
public class OrderRepository {
    public void create(Order o) { /* INSERT */ }
    public List<Order> findByCustomer(int customerId) { /* SELECT */ }
}
```

### 4️⃣ Service
```java
public class OrderService {
    public void placeOrder(Order o) { /* 주문 처리 */ }
    public void cancelOrder(int id) { /* 상태 변경 */ }
}
```

### 5️⃣ Controller
```java
@Controller
@RequestMapping("/order")
public class OrderController {
    @GetMapping("/list") public String list(...) { ... }
    @PostMapping("/create") public String create(...) { ... }
}
```

### 6️⃣ JSP 화면
- `/WEB-INF/views/order/list.jsp`
- `/WEB-INF/views/order/form.jsp`

## 🛠️ Admin (관리자 기능)

### 1️⃣ 관리자 계정 테이블
```sql
CREATE TABLE admin (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50),
    password VARCHAR(100)
);
```

### 2️⃣ 기능 구성
- 도서 관리: 기존 BookController에 관리자 전용 기능 추가
- 회원 관리: Customer 목록 조회 및 삭제
- 주문 관리: 전체 주문 목록, 상태 변경
- 통계: 월별 주문 수, 인기 도서

### 3️⃣ Controller
```java
@Controller
@RequestMapping("/admin")
public class AdminController {
    @GetMapping("/login") public String loginForm() { return "admin/login"; }
    @PostMapping("/login") public String login(...) { ... }
    @GetMapping("/dashboard") public String dashboard(...) { ... }
}
```

### 4️⃣ JSP 화면
- `/WEB-INF/views/admin/login.jsp`
- `/WEB-INF/views/admin/dashboard.jsp`

## 🌐 REST API 기능

### 1️⃣ Book API 예시
```java
@RestController
@RequestMapping("/api/books")
public class BookApiController {
    @GetMapping public List<Book> getAll() { return bookService.findAll(); }
    @PostMapping public void create(@RequestBody Book b) { bookService.save(b); }
}
```

### 2️⃣ Customer API 예시
```java
@RestController
@RequestMapping("/api/customers")
public class CustomerApiController {
    @GetMapping public List<Customer> getAll() { return customerService.findAll(); }
}
```

### 3️⃣ Order API 예시
```java
@RestController
@RequestMapping("/api/orders")
public class OrderApiController {
    @PostMapping public void create(@RequestBody Order o) { orderService.placeOrder(o); }
}
```

### 4️⃣ 테스트 방법
- Postman 또는 curl로 API 호출
- JSON 형식으로 요청/응답 처리

---

## 🔐 인증 및 보안

- 로그인 시 `HttpSession`에 사용자 정보 저장
- 관리자 URL은 인터셉터로 보호 (`HandlerInterceptor`)
- REST API는 추후 JWT 또는 토큰 기반 인증으로 확장 가능

---

이제 각 기능별로 DB → DTO → Repository → Service → Controller → JSP → API까지 전체 흐름
