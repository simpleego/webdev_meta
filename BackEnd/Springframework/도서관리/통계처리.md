# 통계처리
> **도서별 매출**, **고객 지역 분포**, **시간대별 주문량**을 시각화하는 방법
> 
---

## 📚 1. 도서별 매출 시각화

### 🔍 목적
- 어떤 도서가 가장 많은 매출을 올렸는지 파악
- 마케팅/재고 전략에 활용

### 🧮 백엔드 SQL 예시

```sql
SELECT b.bookname, SUM(o.price) AS total_sales
FROM orders o
JOIN book b ON o.book_id = b.id
GROUP BY b.bookname
ORDER BY total_sales DESC;
```

### 📊 프론트엔드 (BarChart 활용)

```svelte
<BarChart
  labels={['도서1', '도서2', '도서3']}
  data={[120000, 95000, 87000]}
  title="📚 도서별 매출"
/>
```

---

## 🗺️ 2. 고객 지역 분포

### 🔍 목적
- 고객이 많이 몰리는 지역 파악
- 지역별 마케팅 전략 수립

### 🧮 백엔드 SQL 예시

```sql
SELECT address_city AS city, COUNT(*) AS customer_count
FROM customer
GROUP BY address_city
ORDER BY customer_count DESC;
```

### 📊 프론트엔드 (PieChart or DoughnutChart)

```svelte
<PieChart
  labels={['서울', '대전', '부산']}
  data={[120, 85, 60]}
  title="🗺️ 고객 지역 분포"
/>
```

---

## ⏰ 3. 시간대별 주문량

### 🔍 목적
- 주문이 몰리는 시간대 파악
- 서버 부하 관리 및 이벤트 타이밍 조정

### 🧮 백엔드 SQL 예시

```sql
SELECT HOUR(order_date) AS hour, COUNT(*) AS order_count
FROM orders
GROUP BY hour
ORDER BY hour;
```

### 📊 프론트엔드 (LineChart 활용)

```svelte
<LineChart
  labels={['0시', '1시', ..., '23시']}
  data={[5, 3, 2, ..., 12]}
  title="⏰ 시간대별 주문량"
/>
```

---

## 🎨 시각화 팁

- **색상**: 시간대는 점진적 색상, 지역은 대비 강한 색상 추천
- **툴팁**: 마우스 오버 시 상세 수치 표시
- **반응형**: 모바일에서도 잘 보이도록 `responsive: true` 설정
