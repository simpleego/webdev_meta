# 인터넷 서점
> **Spring Framework 기반 웹 프로젝트**로 개발
> 전체 개발 과정을 **기획부터 배포까지 단계별 개발 내용**

---

## 🧭 1. **요구사항 분석 및 기획**

### ✅ 주요 기능
- 회원가입 / 로그인 / 마이페이지
- 도서 목록 조회 / 검색 / 상세보기
- 장바구니 / 주문 / 결제
- 리뷰 / 평점 / 추천
- 관리자 페이지 (도서 등록, 재고 관리, 주문 관리)

### ✅ 기술 스택
- **백엔드**: Spring Boot, Spring Security, Spring Data JPA
- **프론트엔드**: Thymeleaf 또는 React
- **DB**: MySQL 또는 PostgreSQL
- **배포**: AWS EC2, S3, RDS, Docker

---

## 🏗 2. **프로젝트 구조 설계 (MVC 기반)**

```plaintext
com.bookstore
├── controller       # 웹 요청 처리
├── service          # 비즈니스 로직
├── repository       # DB 접근
├── domain           # Entity 클래스
├── dto              # 데이터 전달 객체
├── config           # 설정 (보안, JPA 등)
└── exception        # 예외 처리
```

---

## 🗂 3. **데이터베이스 모델링**

### ✅ 주요 테이블
- `User`: 회원 정보
- `Book`: 도서 정보
- `Order`: 주문 정보
- `Cart`: 장바구니
- `Review`: 리뷰 및 평점
- `Category`: 도서 분류
- `Admin`: 관리자 계정

## 🔐 4. **회원 기능 구현**

### ✅ 기능 목록
- 회원가입 / 로그인 / 로그아웃
- 비밀번호 암호화 (BCrypt)
- 권한 설정 (일반 사용자 vs 관리자)

- 추천 도서 (인기순, 평점순)

## 🎨 8. **프론트엔드 구성**

### ✅ 선택지
- **Thymeleaf**: 서버 사이드 렌더링
- **React**: REST API 기반 SPA
- **Bootstrap / Tailwind**: UI 스타일링

---

## 🧪 9. **테스트 및 예외 처리**

### ✅ 테스트
- 단위 테스트 (JUnit, Mockito)
- 통합 테스트 (SpringBootTest)
- MockMvc를 통한 컨트롤러 테스트

### ✅ 예외 처리
- `@ControllerAdvice` + `@ExceptionHandler`로 전역 처리
- 사용자 친화적인 에러 메시지 제공

---

## 🚀 10. **배포 및 운영**

### ✅ 배포 방식
- Docker로 컨테이너화
- AWS EC2 + RDS + S3
- CI/CD: GitHub Actions 또는 Jenkins

### ✅ 운영 관리
- 로그 관리 (Logback, ELK)
- 모니터링 (Prometheus, Grafana)
- 보안 강화 (HTTPS, 인증 토큰)
