## 🛠️ 설치 및 설정 단계

### 1. JDK 17 설치
- [Oracle JDK](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html) 또는 [OpenJDK](https://jdk.java.net/17/) 설치
- 설치 후 `java -version`으로 확인

### 2. IntelliJ IDEA Ultimate 설치
- [IntelliJ 공식 사이트](https://www.jetbrains.com/idea/)에서 Ultimate 버전 다운로드
- JDK 17을 IntelliJ에서 인식하도록 설정 (`Project Structure > SDK`)

### 3. MySQL 설치 및 설정
- [MySQL Community Edition](https://dev.mysql.com/downloads/mysql/) 설치
- 기본 포트: `3306`, 사용자: `root`, 비밀번호 설정
- IntelliJ에서 Database Tool 으로 연결 테스트 가능

### 4. Spring Boot 프로젝트 생성
- IntelliJ에서 `New Project > Spring Initializr` 선택
- 설정 예시:
  - Project: Maven
  - Language: Java
  - Spring Boot: 3.x
  - Dependencies:
    - Spring Web
    - Spring JDBC
    - Thymeleaf
    - MySQL Driver

### 5. application.properties 설정 예시
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/student_db?useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=비밀번호
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

spring.thymeleaf.cache=false
spring.mvc.view.prefix=/templates/
spring.mvc.view.suffix=.html
```

### 6. 디렉토리 구조 예시
```
src/
 └─ main/
     ├─ java/
     │   └─ com.example.demo/
     │       ├─ controller/
     │       ├─ service/
     │       └─ repository/
     └─ resources/
         ├─ templates/
         └─ application.properties
```
