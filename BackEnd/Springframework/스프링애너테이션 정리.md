## 핵심 스프링 애너테이션

**@Component 계열**
- `@Component`: 일반적인 스프링 빈으로 등록
- `@Service`: 비즈니스 로직을 담당하는 서비스 계층
- `@Repository`: 데이터 접근 계층 (DAO)
- `@Controller`: MVC 패턴의 컨트롤러
- `@RestController`: RESTful API를 위한 컨트롤러 (@Controller + @ResponseBody)

**의존성 주입**
- `@Autowired`: 자동 의존성 주입
- `@Qualifier`: 같은 타입의 여러 빈 중 특정 빈 선택
- `@Primary`: 우선순위가 높은 빈 지정
- `@Value`: 프로퍼티 값 주입

**설정 관련**
- `@Configuration`: 설정 클래스 정의
- `@Bean`: 메서드가 스프링 빈을 생성함을 명시
- `@ComponentScan`: 컴포넌트 스캔 범위 지정

## 스프링 부트 전용 애너테이션

**메인 애너테이션**
- `@SpringBootApplication`: 스프링 부트 애플리케이션 진입점 (@Configuration + @EnableAutoConfiguration + @ComponentScan)
- `@EnableAutoConfiguration`: 자동 설정 활성화

**조건부 설정**
- `@ConditionalOnProperty`: 특정 프로퍼티 조건
- `@ConditionalOnClass`: 특정 클래스 존재 조건
- `@Profile`: 특정 프로파일에서만 활성화

## 웹 개발 애너테이션

**요청 매핑**
- `@RequestMapping`: HTTP 요청을 메서드에 매핑
- `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`: HTTP 메서드별 매핑

**파라미터 바인딩**
- `@RequestParam`: 요청 파라미터 바인딩
- `@PathVariable`: URL 경로 변수 바인딩
- `@RequestBody`: HTTP 요청 본문을 객체로 변환
- `@ResponseBody`: 반환값을 HTTP 응답 본문으로 변환

**검증**
- `@Valid`: JSR-303 기반 유효성 검증
- `@Validated`: 스프링의 검증 기능 활성화

## JPA 관련 애너테이션

**엔티티 관련**
- `@Entity`: JPA 엔티티 클래스
- `@Table`: 테이블 매핑 정보
- `@Id`: 기본키 필드
- `@GeneratedValue`: 기본키 자동 생성 전략
- `@Column`: 컬럼 매핑 정보

**관계 매핑**
- `@OneToMany`, `@ManyToOne`, `@OneToOne`, `@ManyToMany`: 연관관계 매핑

## 트랜잭션 및 캐시

**트랜잭션**
- `@Transactional`: 트랜잭션 경계 설정

**캐시**
- `@Cacheable`: 캐시 저장
- `@CacheEvict`: 캐시 삭제
- `@EnableCaching`: 캐시 기능 활성화

## 테스트 애너테이션

- `@SpringBootTest`: 통합 테스트
- `@WebMvcTest`: MVC 계층 테스트
- `@DataJpaTest`: JPA 테스트
- `@MockBean`: 테스트용 Mock 빈 생성

## 보안 관련

- `@EnableWebSecurity`: 스프링 시큐리티 설정
- `@PreAuthorize`, `@PostAuthorize`: 메서드 수준 보안
- `@Secured`: 역할 기반 접근 제어

특히 `@SpringBootApplication`, `@RestController`, `@Service`, `@Repository`, `@Autowired`는 거의 모든 스프링 부트 프로젝트에서 사용되는 기본 애너테이션
