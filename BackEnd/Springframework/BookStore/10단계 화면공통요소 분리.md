# 10단계 화면공통요소 분리.md
> Thymeleaf의 **`fragment`** 기능을 사용하면 웹 페이지의 공통 영역(상단 헤더, 메뉴, 하단 푸터 등)을
> 별도의 파일로 분리하여 효율적으로 관리하고 재사용할 수 있습니다.

-----

### 1\. 📂 프로젝트 파일 구조 변경

공통 fragment 파일들을 모아둘 `fragments` 폴더를 `templates` 내에 생성합니다.

```
/src/main/resources/templates/
├── bookList.html          // 도서 목록 페이지 (이제 공통 부분을 호출)
├── addBookForm.html       // 도서 등록 페이지 (이제 공통 부분을 호출)
└── fragments/             // 공통 UI 조각들을 모아두는 폴더
    ├── header.html        // 상단 헤더 및 메뉴 fragment
    └── footer.html        // 하단 푸터 fragment
```

### 2\. 📝 공통 Fragment 파일 작성

#### 2.1 상단 헤더 및 메뉴 (`header.html`)

페이지의 상단에 항상 표시될 로고, 제목, 그리고 메뉴(네비게이션)를 포함하는 fragment를 만듭니다.

  - **`th:fragment="headerFragment"`**: 이 HTML 조각의 이름을 `headerFragment`로 지정합니다. 다른 페이지에서 이 이름을 사용해 해당 부분을 불러올 수 있습니다.

<!-- end list -->

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>
    <header th:fragment="headerFragment">
        <div style="background-color: #f8f9fa; padding: 20px; text-align: center; border-bottom: 1px solid #dee2e6;">
            <h1>
                <a th:href="@{/}" style="text-decoration: none; color: black;">📚 마당서점</a>
            </h1>
            <nav>
                <a th:href="@{/books}" style="margin: 0 15px;">도서 목록</a>
                <a th:href="@{/books/new}" style="margin: 0 15px;">도서 등록</a>
            </nav>
        </div>
    </header>
</body>
</html>
```

#### 2.2 하단 푸터 (`footer.html`)

페이지 하단에 들어갈 저작권 정보 등을 포함하는 fragment를 만듭니다.

  - **`th:fragment="footerFragment"`**: 이 조각의 이름은 `footerFragment`로 지정합니다.

<!-- end list -->

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>
    <footer th:fragment="footerFragment" style="text-align: center; padding: 20px; margin-top: 40px; background-color: #343a40; color: white;">
        <p>&copy; 2025 Madang Bookstore. All rights reserved.</p>
    </footer>
</body>
</html>
```

### 3\. 📖 기존 페이지에 Fragment 적용하기

이제 `bookList.html`과 같은 기존 페이지에서 반복되던 `header`와 `footer` 코드를 제거하고, 방금 만든 fragment를 `th:replace` 속성을 사용하여 삽입합니다.

#### `bookList.html` (수정된 버전)

  - **`th:replace="~{fragments/header :: headerFragment}"`**: `templates` 폴더 밑의 `fragments/header.html` 파일에서 `headerFragment`라는 이름을 가진 fragment를 찾아, 이 `<div>` 태그 전체를 해당 fragment로 **교체**하라는 의미입니다.
      - `~{...}`는 Thymeleaf에서 fragment를 표현하는 전용 구문입니다.

<!-- end list -->

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>도서 목록</title>
    <style> 
        body { margin: 0; }
        main { padding: 20px; }
        table { border-collapse: collapse; width: 80%; margin: 20px auto; }
        th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
        th { background-color: #f2f2f2; }
        .pagination { text-align: center; margin-top: 20px; }
        .pagination a { margin: 0 5px; text-decoration: none; }
        .pagination .current { font-weight: bold; }
        .search-form { text-align: center; margin: 20px; }
    </style>
</head>
<body>

    <div th:replace="~{fragments/header :: headerFragment}"></div>

    <main>
        <h2 style="text-align: center;">도서 목록 및 검색</h2>
    
        <div class="search-form">
            <form th:action="@{/books}" method="get">
                <input type="text" name="keyword" placeholder="도서명 또는 출판사 검색" th:value="${keyword}">
                <button type="submit">검색</button>
            </form>
        </div>
    
        <table>
            </table>
    
        <div class="pagination">
            </div>
    </main>
    <div th:replace="~{fragments/footer :: footerFragment}"></div>

</body>
</html>
```

### 적용 결과

  - **`addBookForm.html`** 이나 다른 페이지들도 위와 동일한 방식으로 `th:replace`를 사용하여 `header`와 `footer`를 추가하면 됩니다.
  - 이제 헤더의 메뉴를 수정하거나 푸터의 연도를 변경해야 할 때, `header.html`과 `footer.html` 파일만 수정하면 이 fragment를 사용하는 모든 페이지에 **자동으로 변경 사항이 반영**됩니다.
  - 코드의 중복이 사라져 **유지보수가 매우 편리**해집니다.
