# 도서목록 페이징

-----

### \#\# 1단계: Mapper 수정 (`BookMapper`)

데이터베이스에서 전체 도서 개수를 세는 쿼리와, 특정 범위의 도서만 가져오는 페이징 쿼리를 추가합니다.

#### **`BookMapper.java`** (인터페이스 수정)

`countAll`과 `findAllPaged` 메서드 선언을 추가합니다. 여러 파라미터를 넘기기 위해 `@Param` 어노테이션을 사용합니다.

```java
package com.example.project.mapper;

import com.example.project.domain.Book;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param; // @Param import
import java.util.List;
import java.util.Optional;

@Mapper
public interface BookMapper {
    void save(Book book);
    Optional<Book> findById(Long bookId);
    List<Book> findAll();

    // 페이징을 위한 메서드 추가
    int countAll(); // 전체 도서 개수 조회
    List<Book> findAllPaged(@Param("limit") int limit, @Param("offset") int offset); // 페이지 단위로 도서 조회
}
```

#### **`mappers/BookMapper.xml`** (SQL 쿼리 추가)

`countAll`과 `findAllPaged`에 대한 SQL을 작성합니다. 도서 ID의 내림차순으로 정렬하여 최신 도서가 먼저 보이게 합니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.project.mapper.BookMapper">

    <!-- ... 기존 save, findById, findAll 쿼리 생략 ... -->

    <!-- 전체 도서 개수를 세는 쿼리 -->
    <select id="countAll" resultType="int">
        SELECT COUNT(*) FROM Book
    </select>

    <!-- 페이지 단위로 도서를 조회하는 쿼리 (MySQL/MariaDB 기준) -->
    <select id="findAllPaged" resultType="Book">
        SELECT *
        FROM Book
        ORDER BY bookid DESC
        LIMIT #{limit} OFFSET #{offset}
    </select>
</mapper>
```

### \#\# 2단계: 페이징 정보 DTO 및 서비스 로직 수정

페이징 결과를 담을 DTO(Data Transfer Object)를 만들고, 서비스 계층에서 페이징 계산 로직을 구현합니다.

#### **페이징 결과 DTO 생성 (`PagedResult.java`, `PageInfo.java`)**

`com.example.project` 아래에 `dto` 패키지를 새로 만들고, 페이징 관련 클래스 두 개를 생성합니다.

  * **`dto/PageInfo.java`**: 현재 페이지, 전체 페이지 수 등의 페이징 정보를 담는 클래스

    ```java
    package com.example.project.dto;

    import lombok.AllArgsConstructor;
    import lombok.Data;

    @Data
    @AllArgsConstructor
    public class PageInfo {
        private int currentPage;
        private int totalPages;
    }
    ```

  * **`dto/PagedResult.java`**: 실제 데이터 목록(도서 목록)과 페이징 정보를 함께 담아서 컨트롤러로 전달하는 클래스

    ```java
    package com.example.project.dto;

    import com.example.project.domain.Book;
    import lombok.AllArgsConstructor;
    import lombok.Data;
    import java.util.List;

    @Data
    @AllArgsConstructor
    public class PagedResult {
        private List<Book> content;
        private PageInfo pageInfo;
    }
    ```

#### **`BookService.java` 수정**

기존의 `findBooks()`는 그대로 두고, 페이징 처리를 위한 `findBooksPaged()` 메서드를 새로 만듭니다.

```java
// ...
import com.example.project.dto.PagedResult; // DTO import
import com.example.project.dto.PageInfo;    // DTO import
// ...

@Service
public class BookService {
    // ... 기존 코드 생략

    public PagedResult findBooksPaged(int page, int size) {
        // 'page'는 1부터 시작, 'offset'은 0부터 시작
        int offset = (page - 1) * size;
        
        // 1. 현재 페이지에 해당하는 도서 목록 조회
        List<Book> books = bookMapper.findAllPaged(size, offset);
        
        // 2. 전체 도서 개수 조회
        int totalElements = bookMapper.countAll();
        
        // 3. 전체 페이지 수 계산
        int totalPages = (int) Math.ceil((double) totalElements / size);
        if (totalPages == 0) totalPages = 1; // 도서가 하나도 없을 경우 1페이지로 설정

        // 4. 페이징 정보와 도서 목록을 DTO에 담아 반환
        PageInfo pageInfo = new PageInfo(page, totalPages);
        return new PagedResult(books, pageInfo);
    }
}
```

### \#\# 3단계: 컨트롤러 및 뷰(View) 수정

#### **`HomeController.java` 수정**

메인 페이지 요청 시 `page` 파라미터를 받아서 페이징 처리된 결과를 모델에 담도록 수정합니다.

```java
// ...
import org.springframework.web.bind.annotation.RequestParam; // RequestParam import
import com.example.project.dto.PagedResult; // DTO import
// ...

@Controller
public class HomeController {

    private final BookService bookService;

    public HomeController(BookService bookService) {
        this.bookService = bookService;
    }

    @GetMapping("/")
    public String home(@RequestParam(value = "page", defaultValue = "1") int page, // page 파라미터 받기, 기본값 1
                       HttpSession session,
                       Model model) {

        if (session.getAttribute("loginMember") != null) {
            int pageSize = 10; // 페이지 당 10개씩 표시
            PagedResult pagedResult = bookService.findBooksPaged(page, pageSize);
            model.addAttribute("pagedResult", pagedResult);
        }
        return "home";
    }
}
```

#### **`home.html` 수정**

Thymeleaf를 사용하여 도서 목록과 페이지 번호를 출력합니다.

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<!-- ... head 생략 ... -->
<head>
    <title>도서 주문 시스템</title>
    <!-- 간단한 페이징 UI를 위한 스타일 추가 -->
    <style>
        .pagination { display: flex; justify-content: center; padding: 1em 0; list-style: none; }
        .pagination li { margin: 0 5px; }
        .pagination li a { text-decoration: none; padding: 5px 10px; border: 1px solid #ddd; color: #337ab7; }
        .pagination li.active a { background-color: #337ab7; color: white; border-color: #337ab7; }
        .pagination li.disabled a { color: #777; pointer-events: none; background-color: #fff; border-color: #ddd; }
    </style>
</head>
<body>
    <!-- ... 상단 로그인/로그아웃 정보 생략 ... -->
    <div th:if="${session.loginMember != null}">
        <!-- ... 환영 메시지, 링크 등 생략 ... -->
        <hr>
        <h3>🛒 구매 가능 도서 목록</h3>
        <table border="1" style="width: 100%; text-align: center;">
            <thead>
                <tr>
                    <th>이미지</th>
                    <th>책 제목</th>
                    <th>출판사</th>
                    <th>가격</th>
                </tr>
            </thead>
            <tbody>
                <!-- pagedResult.content로 변경 -->
                <tr th:each="book : ${pagedResult.content}">
                    <td>
                        <img th:if="${book.storedFilename}" th:src="@{/images/{filename}(filename=${book.storedFilename})}" width="50" alt="book image">
                        <span th:unless="${book.storedFilename}">이미지 없음</span>
                    </td>
                    <td>
                        <a th:href="@{/books/{id}(id=${book.bookid})}" th:text="${book.bookname}"></a>
                    </td>
                    <td th:text="${book.publisher}"></td>
                    <td th:text="${book.price}"></td>
                </tr>
            </tbody>
        </table>

        <!-- ===== 페이징 네비게이션 추가 ===== -->
        <div th:if="${pagedResult != null and pagedResult.pageInfo.totalPages > 0}">
            <ul class="pagination">
                <!-- 이전 페이지 버튼 -->
                <li th:classappend="${pagedResult.pageInfo.currentPage == 1} ? 'disabled'">
                    <a th:href="@{/(page=${pagedResult.pageInfo.currentPage - 1})}"><span>&laquo;</span></a>
                </li>

                <!-- 페이지 번호 버튼 -->
                <li th:each="i : ${#numbers.sequence(1, pagedResult.pageInfo.totalPages)}"
                    th:classappend="${i == pagedResult.pageInfo.currentPage} ? 'active'">
                    <a th:href="@{/(page=${i})}" th:text="${i}"></a>
                </li>

                <!-- 다음 페이지 버튼 -->
                <li th:classappend="${pagedResult.pageInfo.currentPage == pagedResult.pageInfo.totalPages} ? 'disabled'">
                    <a th:href="@{/(page=${pagedResult.pageInfo.currentPage + 1})}"><span>&raquo;</span></a>
                </li>
            </ul>
        </div>
    </div>
</body>
</html>
```
