# 8단계 마이바티스_파일업다운로드_페이징
> 마당도서 DB 테이블 구조를 바탕으로 스프링 부트, MyBatis, Thymeleaf를 사용하여
> 요청하신 도서 관리 기능(검색, 등록, 이미지 업로드/다운로드, 페이징)을 구현하는 전체적인 방법을 단계별로 안내해 드리겠습니다.

## 🏢 프로젝트 기본 구조 및 설정

먼저 프로젝트의 기본 구조와 필요한 설정을 구성합니다.

`Maven` 프로젝트 기준으로 필요한 라이브러리를 `pom.xml`에 추가합니다.

```xml
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>

```

### 2\. `application.properties` 설정

DB 연결 정보, MyBatis 매퍼 위치, 파일 업로드 경로 등을 설정합니다.

```properties
# src/main/resources/application.properties

# --- Database Settings ---
spring.datasource.driver-class-name=org.mariadb.jdbc.Driver
spring.datasource.url=jdbc:mariadb://localhost:3306/your_db_name
spring.datasource.username=your_username
spring.datasource.password=your_password

# --- MyBatis Settings ---
# Mapper XML 파일의 위치를 지정합니다.
mybatis.mapper-locations=mappers/*.xml
# DTO 클래스의 패키지 경로를 지정하여 XML에서 짧은 별칭을 사용할 수 있게 합니다.
mybatis.type-aliases-package=com.example.bookstore.dto

# --- File Upload Settings ---
# 파일 업로드 경로 (시스템에 맞게 수정하세요)
file.upload-dir=C:/uploads/
# 최대 파일 크기
spring.servlet.multipart.max-file-size=10MB
# 최대 요청 크기
spring.servlet.multipart.max-request-size=10MB
```

### 3\. DTO(Data Transfer Object) 생성

`Book` 테이블과 매핑될 `BookDTO` 클래스를 생성합니다. 이미지 파일 처리를 위해 `MultipartFile`과 저장될 파일명을 위한 필드를 추가합니다.

```java
// com/example/bookstore/dto/BookDTO.java
package com.example.bookstore.dto;

import lombok.Data;
import org.springframework.web.multipart.MultipartFile;

@Data // Lombok을 사용하여 Getter, Setter, toString 등을 자동 생성
public class BookDTO {
    private int bookid;
    private String bookname;
    private String publisher;
    private int price;

    // 이미지 업로드를 위한 필드
    private MultipartFile imageFile; // HTML <input type="file">의 name과 일치
    private String originalFileName; // 원본 파일명
    private String storedFileName; // 서버에 저장될 파일명
}
```

## 📚 기능별 구현 상세

### 1\. 도서 목록 조회 (페이징 기능 포함)

#### 1.1 Mapper (Interface & XML)

  - **`BookMapper.java` (인터페이스)**

    ```java
    // com/example/bookstore/mapper/BookMapper.java
    package com.example.bookstore.mapper;

    import com.example.bookstore.dto.BookDTO;
    import org.apache.ibatis.annotations.Mapper;
    import java.util.List;
    import java.util.Map;

    @Mapper
    public interface BookMapper {
        // 도서 목록 조회 (검색어와 페이징 정보 포함)
        List<BookDTO> findBooks(Map<String, Object> params);

        // 전체 도서 수 조회 (검색어 포함)
        int countBooks(String keyword);
    }
    ```

  - **`BookMapper.xml` (SQL 쿼리)**
    `LIMIT`와 `OFFSET`을 사용하여 페이징을 구현하고, 검색어가 있을 경우 `WHERE`절을 동적으로 추가합니다.

    ```xml
    <?xml version="1.0" encoding="UTF-8" ?>
    <!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
    <mapper namespace="com.example.bookstore.mapper.BookMapper">

        <select id="findBooks" parameterType="map" resultType="com.example.bookstore.dto.BookDTO">
            SELECT bookid, bookname, publisher, price, storedFileName
            FROM Book
            <where>
                <if test="keyword != null and keyword != ''">
                    bookname LIKE CONCAT('%', #{keyword}, '%')
                    OR publisher LIKE CONCAT('%', #{keyword}, '%')
                </if>
            </where>
            ORDER BY bookid DESC
            LIMIT #{limit} OFFSET #{offset}
        </select>

        <select id="countBooks" parameterType="string" resultType="int">
            SELECT count(bookid) FROM Book
            <where>
                <if test="keyword != null and keyword != ''">
                    bookname LIKE CONCAT('%', #{keyword}, '%')
                    OR publisher LIKE CONCAT('%', #{keyword}, '%')
                </if>
            </where>
        </select>
    </mapper>
    ```

#### 1.2 Service

페이지 계산 로직과 Mapper 호출을 담당합니다.

```java
// com/example/bookstore/service/BookService.java
package com.example.bookstore.service;

import com.example.bookstore.dto.BookDTO;
import com.example.bookstore.mapper.BookMapper;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

@Service
@RequiredArgsConstructor
public class BookService {
    private final BookMapper bookMapper;

    public Map<String, Object> findBooks(String keyword, int page, int size) {
        int offset = (page - 1) * size;

        Map<String, Object> params = new HashMap<>();
        params.put("keyword", keyword);
        params.put("limit", size);
        params.put("offset", offset);

        List<BookDTO> bookList = bookMapper.findBooks(params);
        int totalCount = bookMapper.countBooks(keyword);
        int totalPages = (int) Math.ceil((double) totalCount / size);

        Map<String, Object> result = new HashMap<>();
        result.put("bookList", bookList);
        result.put("currentPage", page);
        result.put("totalPages", totalPages);
        result.put("keyword", keyword);

        return result;
    }
}
```

#### 1.3 Controller

HTTP 요청을 받아 서비스를 호출하고, 결과를 뷰에 전달합니다.

```java
// com/example/bookstore/controller/BookController.java
package com.example.bookstore.controller;

import com.example.bookstore.service.BookService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;

import java.util.Map;

@Controller
@RequiredArgsConstructor
public class BookController {
    private final BookService bookService;

    @GetMapping("/books")
    public String bookList(@RequestParam(value = "keyword", required = false, defaultValue = "") String keyword,
                           @RequestParam(value = "page", defaultValue = "1") int page,
                           Model model) {
        int pageSize = 5; // 한 페이지에 5개씩 보여주기
        Map<String, Object> result = bookService.findBooks(keyword, page, pageSize);

        model.addAttribute("list", result.get("bookList"));
        model.addAttribute("currentPage", result.get("currentPage"));
        model.addAttribute("totalPages", result.get("totalPages"));
        model.addAttribute("keyword", result.get("keyword"));

        return "bookList"; // templates/bookList.html을 렌더링
    }
}
```

#### 2.2 Service (기존 파일에 추가/수정)

파일 저장 로직을 추가합니다. 고유한 파일명을 만들기 위해 UUID를 사용합니다.

```java
// com/example/bookstore/service/BookService.java
import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.multipart.MultipartFile;
import java.io.File;
import java.io.IOException;
import java.util.UUID;
// ...

@Service
@RequiredArgsConstructor
public class BookService {
    private final BookMapper bookMapper;

    @Value("${file.upload-dir}") // application.properties의 값 주입
    private String uploadDir;

    // ... 기존 findBooks 메소드 ...

    public void saveBook(BookDTO bookDTO) throws IOException {
        MultipartFile imageFile = bookDTO.getImageFile();
        if (imageFile != null && !imageFile.isEmpty()) {
            // 원본 파일명
            String originalFileName = imageFile.getOriginalFilename();
            // 서버에 저장될 고유한 파일명 생성
            String storedFileName = createStoredFileName(originalFileName);

            // 파일 저장
            String fullPath = uploadDir + storedFileName;
            imageFile.transferTo(new File(fullPath));

            // DTO에 파일 정보 설정
            bookDTO.setOriginalFileName(originalFileName);
            bookDTO.setStoredFileName(storedFileName);
        }
        bookMapper.saveBook(bookDTO);
    }
    
    // 고유한 파일명 생성을 위한 메소드
    private String createStoredFileName(String originalFileName) {
        String ext = originalFileName.substring(originalFileName.lastIndexOf("."));
        return UUID.randomUUID().toString() + ext;
    }
}
```

#### 2.3 Controller (기존 파일에 추가)

### 3\. 도서 이미지 다운로드(조회)

#### 3.1 Controller (기존 파일에 추가)

업로드된 이미지를 웹 브라우저에서 볼 수 있도록 URL 경로와 실제 파일 시스템 경로를 매핑해주는 컨트롤러를 추가합니다.

```java
// com/example/bookstore/controller/ImageController.java
package com.example.bookstore.controller;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.Resource;
import org.springframework.core.io.UrlResource;
import org.springframework.http.ResponseEntity;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.ResponseBody;

import java.net.MalformedURLException;

@Controller
public class ImageController {

    @Value("${file.upload-dir}")
    private String uploadDir;

    @GetMapping("/images/{filename}")
    @ResponseBody // HTML 뷰를 통하지 않고, 응답 본문에 직접 데이터를 씀
    public Resource showImage(@PathVariable String filename) throws MalformedURLException {
        // "file:/C:/uploads/filename.jpg" 와 같은 형식으로 리소스 경로를 만듦
        return new UrlResource("file:" + uploadDir + filename);
    }
}
```

  * 이제 `bookList.html`의 `<img th:src="@{/images/{filename}(filename=${book.storedFileName})}">` 코드가 이 컨트롤러와 연결되어 이미지를 정상적으로 불러올 수 있습니다.

### 최종 정리

1.  **환경 설정**: `pom.xml`에 의존성을 추가하고 `application.properties`에 DB, MyBatis, 파일 경로를 설정합니다.
2.  **DTO**: `BookDTO`에 DB 컬럼과 파일 처리를 위한 필드를 정의합니다.
3.  **Mapper**: `BookMapper` 인터페이스와 XML 파일을 만들어 각 기능에 필요한 SQL 쿼리를 작성합니다. (페이징, 검색, 등록)
4.  **Service**: 비즈니스 로직(페이지 계산, 파일 저장 등)을 처리하고 Mapper를 호출합니다.
5.  **Controller**: 웹 요청을 받아 Service를 호출하고, 그 결과를 Model에 담아 Thymeleaf 뷰로 전달합니다. 이미지 조회를 위한 별도 컨트롤러도 작성합니다.
6.  **View (Thymeleaf)**: `bookList.html`에서 목록, 검색, 페이징 UI를 구현하고 `addBookForm.html`에서 등록 UI를 구현합니다.

이제 이 코드를 기반으로 프로젝트를 실행하면 요청하신 모든 기능이 정상적으로 동작할 것입니다.
