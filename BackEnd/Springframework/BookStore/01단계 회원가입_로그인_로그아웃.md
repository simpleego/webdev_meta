# 스프링 부트(Spring Boot)와 Spring JDBC Template, MySQL, Thymeleaf를 사용하여 회원 가입, 로그인, 로그아웃 기능을 구현
> 회원 가입 시에는 아이디 중복 확인 기능이 포함됩니다.

-----

### 📝 1단계: 프로젝트 환경설정

먼저, Spring Boot 프로젝트를 생성하고 필요한 의존성을 추가합니다.

#### **`build.gradle`**

```groovy
plugins {
    id 'java'
    id 'org.springframework.boot' version '3.2.4' // Spring Boot 버전
    id 'io.spring.dependency-management' version '1.1.4'
}

group = 'com.example'
version = '0.0.1-SNAPSHOT'

java {
    sourceCompatibility = '17' // Java 17 사용
}

// Lombok 설정을 위함
configurations {
    compileOnly {
        extendsFrom annotationProcessor
    }
}

repositories {
    mavenCentral()
}

dependencies {
    // Spring Web: Spring MVC를 사용하기 위한 필수 라이브러리
    implementation 'org.springframework.boot:spring-boot-starter-web'
    // Thymeleaf: HTML 템플릿 엔진
    implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
    // Spring JDBC: JdbcTemplate을 사용하기 위한 라이브러리
    implementation 'org.springframework.boot:spring-boot-starter-jdbc'
    // MySQL Connector: MySQL 데이터베이스 연동을 위한 드라이버
    runtimeOnly 'com.mysql:mysql-connector-j'
    // Lombok: 반복적인 코드를 줄여주는 라이브러리 (Getter, Setter 등)
    compileOnly 'org.projectlombok:lombok'
    annotationProcessor 'org.projectlombok:lombok'
    // DevTools: 개발 편의성을 위한 라이브러리 (자동 재시작 등)
    developmentOnly 'org.springframework.boot:spring-boot-devtools'
    // Test: 테스트 코드 작성을 위한 라이브러리
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}

tasks.named('test') {
    useJUnitPlatform()
}
```

#### **`application.properties`**

`src/main/resources/application.properties` 파일에 DB 연결 정보를 입력합니다.


#### **1. 데이터베이스 테이블 생성**

로그인 기능을 위해 `Customer` 테이블에 `username`과 `password` 컬럼을 추가하여 테이블을 생성합니다.

```sql
CREATE TABLE Customer (
    custid BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    username VARCHAR(255) NOT NULL UNIQUE, -- 로그인 아이디
    password VARCHAR(255) NOT NULL,       -- 로그인 비밀번호
    address VARCHAR(255),
    phone VARCHAR(255)
);
```

#### **2. Domain: `Customer.java`**

DB 테이블과 매핑될 `Customer` 객체입니다. Lombok의 `@Data` 어노테이션을 사용하여 Getter, Setter 등을 자동으로 생성합니다.

```java
package com.example.project.domain;

import lombok.Data;

@Data
public class Customer {
    private Long custid;
    private String name;
    private String username; // 아이디 추가
    private String password; // 비밀번호 추가
    private String address;
    private String phone;
}
```

#### **3. Repository: `CustomerRepository.java`**

`JdbcTemplate`을 사용하여 DB와 직접 통신하는 클래스입니다.

```java
package com.example.project.repository;

import com.example.project.domain.Customer;
import org.springframework.dao.EmptyResultDataAccessException;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;
import org.springframework.stereotype.Repository;

import javax.sql.DataSource;
import java.util.Optional;

@Repository
public class CustomerRepository {

    private final JdbcTemplate jdbcTemplate;

    public CustomerRepository(DataSource dataSource) {
        this.jdbcTemplate = new JdbcTemplate(dataSource);
    }

    // Customer 객체와 DB 결과를 매핑하기 위한 RowMapper
    private RowMapper<Customer> customerRowMapper() {
        return (rs, rowNum) -> {
            Customer customer = new Customer();
            customer.setCustid(rs.getLong("custid"));
            customer.setName(rs.getString("name"));
            customer.setUsername(rs.getString("username"));
            customer.setPassword(rs.getString("password"));
            customer.setAddress(rs.getString("address"));
            customer.setPhone(rs.getString("phone"));
            return customer;
        };
    }

    // 회원 정보 저장
    public Customer save(Customer customer) {
        String sql = "INSERT INTO Customer(name, username, password, address, phone) VALUES(?, ?, ?, ?, ?)";
        jdbcTemplate.update(sql, customer.getName(), customer.getUsername(), customer.getPassword(), customer.getAddress(), customer.getPhone());
        return customer;
    }

    // 아이디(username)로 회원 찾기
    public Optional<Customer> findByUsername(String username) {
        String sql = "SELECT * FROM Customer WHERE username = ?";
        try {
            Customer customer = jdbcTemplate.queryForObject(sql, customerRowMapper(), username);
            return Optional.of(customer);
        } catch (EmptyResultDataAccessException e) {
            return Optional.empty(); // 결과가 없으면 Optional.empty() 반환
        }
    }
}
```

#### **4. Service: `MemberService.java`**

회원 가입, 로그인 등 핵심 비즈니스 로직을 처리합니다. 회원 가입 시 아이디 중복 검사를 수행합니다.

```java
package com.example.project.service;

import com.example.project.domain.Customer;
import com.example.project.repository.CustomerRepository;
import org.springframework.stereotype.Service;

import java.util.Optional;

@Service
public class MemberService {

    private final CustomerRepository customerRepository;

    public MemberService(CustomerRepository customerRepository) {
        this.customerRepository = customerRepository;
    }

    /**
     * 회원 가입
     */
    public Long join(Customer customer) {
        // 아이디 중복 확인
        validateDuplicateMember(customer);
        customerRepository.save(customer);
        return customer.getCustid();
    }

    private void validateDuplicateMember(Customer customer) {
        customerRepository.findByUsername(customer.getUsername())
                .ifPresent(m -> {
                    throw new IllegalStateException("이미 존재하는 아이디입니다.");
                });
    }

    /**
     * 로그인
     */
    public Optional<Customer> login(String username, String password) {
        return customerRepository.findByUsername(username)
                .filter(c -> c.getPassword().equals(password));
    }
}
```

사용자의 요청을 받아 처리하고, 적절한 View를 반환합니다.

  * **`MemberController.java`**: 회원 관련 기능(가입, 로그인, 로그아웃)을 담당합니다.

```java
package com.example.project.controller;

import com.example.project.domain.Customer;
import com.example.project.service.MemberService;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpSession;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.servlet.mvc.support.RedirectAttributes;
import java.util.Optional;

// 회원가입 폼 데이터를 받기 위한 클래스
class CustomerForm {
    private String name;
    private String username;
    private String password;
    private String address;
    private String phone;
    // Lombok을 사용하지 않는 경우, 수동으로 Getter/Setter 추가 필요
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    // ... 다른 필드들도 동일하게 추가
}


@Controller
public class MemberController {

    private final MemberService memberService;

    public MemberController(MemberService memberService) {
        this.memberService = memberService;
    }

    // 회원 가입 폼으로 이동
    @GetMapping("/members/new")
    public String createForm() {
        return "members/createMemberForm";
    }

    // 회원 가입 처리
    @PostMapping("/members/new")
    public String create(CustomerForm form, RedirectAttributes redirectAttributes) {
        Customer customer = new Customer();
        customer.setName(form.getName());
        customer.setUsername(form.getUsername());
        customer.setPassword(form.getPassword());
        customer.setAddress(form.getAddress());
        customer.setPhone(form.getPhone());

        try {
            memberService.join(customer);
        } catch (IllegalStateException e) {
            // 중복 아이디 예외 발생 시, 메시지를 담아 리다이렉트
            redirectAttributes.addFlashAttribute("errorMessage", e.getMessage());
            return "redirect:/members/new";
        }

        return "redirect:/"; // 가입 성공 시 홈으로 리다이렉트
    }

    // 로그인 폼으로 이동
    @GetMapping("/members/login")
    public String loginForm() {
        return "members/loginForm";
    }

    // 로그인 처리
    @PostMapping("/members/login")
    public String login(@RequestParam("username") String username,
                        @RequestParam("password") String password,
                        HttpServletRequest request,
                        RedirectAttributes redirectAttributes) {

        Optional<Customer> loginResult = memberService.login(username, password);

        if (loginResult.isPresent()) {
            // 로그인 성공 시 세션 생성
            HttpSession session = request.getSession();
            session.setAttribute("loginMember", loginResult.get());
            return "redirect:/";
        } else {
            // 로그인 실패 시 메시지와 함께 리다이렉트
            redirectAttributes.addFlashAttribute("errorMessage", "아이디 또는 비밀번호가 맞지 않습니다.");
            return "redirect:/members/login";
        }
    }

    // 로그아웃 처리
    @PostMapping("/members/logout")
    public String logout(HttpServletRequest request) {
        HttpSession session = request.getSession(false); // 세션이 없으면 새로 생성하지 않음
        if (session != null) {
            session.invalidate(); // 세션 무효화
        }
        return "redirect:/";
    }
}
```

### ✅ 3단계: 실행 및 확인

1.  프로젝트를 실행합니다.
2.  브라우저에서 `http://localhost:8080`으로 접속하여 메인 페이지를 확인합니다.
3.  '회원 가입' 링크를 클릭하여 정보를 입력하고 가입을 시도합니다.
      * **중복된 아이디**를 입력하면 "이미 존재하는 아이디입니다."라는 메시지가 표시되는지 확인합니다.
4.  가입이 완료되면 로그인 페이지에서 가입한 아이디와 비밀번호로 로그인을 시도합니다.
5.  로그인 성공 시, 메인 페이지에 환영 메시지와 로그아웃 버튼이 표시되는지 확인합니다.
6.  로그아웃 버튼을 클릭하여 정상적으로 로그아웃되는지 확인합니다.
