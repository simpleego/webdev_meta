# 스프링 암호화 기능
> **Spring Security를 도입하여 회원 가입 및 로그인 시 비밀번호를 안전하게 암호화**하는 기능을 추가

BCrypt라는 강력한 해시 함수를 사용하여 비밀번호를 암호화하며, 이는 현재 업계 표준으로 널리 사용되는 방식입니다.

-----

### 📁 1단계: Spring Security 의존성 추가

`build.gradle` 파일에 Spring Security 라이브러리를 추가합니다.

#### **`build.gradle`**

```groovy
dependencies {
    // ... 기존 의존성 생략

    // Spring Security 추가
    implementation 'org.springframework.boot:spring-boot-starter-security'
}
```

> **참고**: 의존성을 추가한 후에는 Gradle 프로젝트를 새로고침(Reload)해야 라이브러리가 적용됩니다.

-----

### 📁 2단계: Security 설정 클래스 생성

비밀번호 암호화에 사용할 `PasswordEncoder`를 스프링 빈(Bean)으로 등록하는 설정 클래스를 만듭니다.

`com.example.project.config` 패키지에 `SecurityConfig` 클래스를 생성합니다.

```java
package com.example.project.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {

    // BCryptPasswordEncoder를 PasswordEncoder 빈으로 등록
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    // Spring Security의 기본 인증/인가 절차를 비활성화하는 설정
    // 이렇게 해야 우리가 직접 만든 로그인 로직이 정상 동작합니다.
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable()) // CSRF 보호 비활성화 (학습 목적)
            .authorizeHttpRequests(authz -> authz
                .anyRequest().permitAll() // 모든 요청에 대해 인증 없이 접근 허용
            );
        return http.build();
    }
}
```

### 📁 3단계: 서비스 로직 수정 (`MemberService`)

회원 가입, 로그인, 정보 수정 시 암호화 로직을 적용하도록 `MemberService`를 수정합니다.

#### **`MemberService.java`**

```java
package com.example.project.service;

import com.example.project.controller.CustomerForm; // CustomerForm import
import com.example.project.domain.Customer;
import com.example.project.repository.CustomerRepository;
import org.springframework.security.crypto.password.PasswordEncoder; // PasswordEncoder import
import org.springframework.stereotype.Service;

import java.util.Optional;

@Service
public class MemberService {

    private final CustomerRepository customerRepository;
    private final PasswordEncoder passwordEncoder; // PasswordEncoder 주입

    // 생성자를 통해 PasswordEncoder를 주입받음
    public MemberService(CustomerRepository customerRepository, PasswordEncoder passwordEncoder) {
        this.customerRepository = customerRepository;
        this.passwordEncoder = passwordEncoder;
    }

    /**
     * 회원 가입
     */
    public Long join(Customer customer) {
        validateDuplicateMember(customer);
        // 비밀번호를 암호화하여 저장
        String encodedPassword = passwordEncoder.encode(customer.getPassword());
        customer.setPassword(encodedPassword);
        customerRepository.save(customer);
        return customer.getCustid();
    }

    private void validateDuplicateMember(Customer customer) {
        customerRepository.findByUsername(customer.getUsername())
                .ifPresent(m -> {
                    throw new IllegalStateException("이미 존재하는 아이디입니다.");
                });
    }

    /**
     * 로그인
     */
    public Optional<Customer> login(String username, String password) {
        // username으로 회원을 찾은 뒤, 입력된 비밀번호(raw)와 DB의 암호화된 비밀번호를 비교
        return customerRepository.findByUsername(username)
                .filter(c -> passwordEncoder.matches(password, c.getPassword()));
    }

    /**
     * 회원 정보 수정
     */
    public void updateMember(Customer existingCustomer, CustomerForm form) {
        // 이름, 주소, 전화번호 업데이트
        existingCustomer.setName(form.getName());
        existingCustomer.setAddress(form.getAddress());
        existingCustomer.setPhone(form.getPhone());

        // 폼에서 새로운 비밀번호가 입력되었는지 확인
        String newPassword = form.getPassword();
        if (newPassword != null && !newPassword.isBlank()) {
            // 새 비밀번호를 암호화하여 설정
            existingCustomer.setPassword(passwordEncoder.encode(newPassword));
        }

        // Repository를 통해 DB에 최종 업데이트
        customerRepository.update(existingCustomer);
    }
}
```

> ⚠️ **`CustomerForm` import**: `MemberService`에서 `CustomerForm`을 사용하므로, `com.example.project.controller.CustomerForm`을 import 해야 합니다. 만약 `CustomerForm`을 별도의 `dto` 패키지로 옮겼다면 해당 경로로 import 해주세요.

### 📁 4단계: 컨트롤러 수정 (`MemberController`)

회원 정보 수정 시, 수정된 서비스 로직을 호출하도록 `MemberController`의 `update` 메서드를 수정합니다.

#### **`MemberController.java`**

```java
// ... 기존 코드 생략

// 회원 정보 수정 처리
@PostMapping("/members/edit")
public String update(CustomerForm form, HttpSession session, RedirectAttributes redirectAttributes) {
    Customer loginMember = (Customer) session.getAttribute("loginMember");
    if (loginMember == null) {
        return "redirect:/";
    }

    // 서비스 레이어에 회원 정보와 수정할 폼 데이터를 넘겨 업데이트 처리
    memberService.updateMember(loginMember, form);

    // 세션 정보도 최신 상태로 업데이트
    session.setAttribute("loginMember", loginMember);

    redirectAttributes.addFlashAttribute("successMessage", "회원 정보가 성공적으로 수정되었습니다.");
    return "redirect:/";
}
```

### ✅ 5단계: 실행 및 확인

> **🚨 중요\!**
> 암호화 기능을 적용하면 **기존에 일반 텍스트로 저장된 데이터베이스의 비밀번호로는 더 이상 로그인할 수 없습니다.**
> 테스트를 위해 **기존 회원 데이터를 모두 삭제**하고 새로 회원가입을 진행해주세요.

1.  프로젝트를 실행합니다.
2.  **새로운 아이디로 회원가입**을 합니다.
3.  데이터베이스의 `Customer` 테이블을 확인해보면, `password` 컬럼에 알아볼 수 없는 긴 문자열 (암호화된 비밀번호)이 저장된 것을 볼 수 있습니다.
4.  방금 가입한 아이디와 **가입 시 입력했던 원래의 비밀번호**로 로그인을 시도합니다.
5.  정상적으로 로그인되는지 확인합니다.
6.  로그인 후, **회원 정보 수정** 페이지로 이동하여 다른 정보와 함께 비밀번호를 변경해봅니다.
7.  로그아웃 후, **새로 변경한 비밀번호**로 로그인이 잘 되는지 확인합니다.
