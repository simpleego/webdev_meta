# 업로드 이미지명 자동생성
> 스프링부트에서 상품 이미지를 업로드할 때 **파일 이름을 자동 생성**하는 방법은 보통 **UUID** 또는 **타임스탬프 기반**으로 처리합니다.
> 이렇게 하면 파일명이 중복되지 않고, 보안상도 안전하죠. 

---

### 🛠️ 1. UUID 기반 자동 파일명 생성

```java
import java.util.UUID;

public String generateFileName(String originalFilename) {
    String extension = originalFilename.substring(originalFilename.lastIndexOf("."));
    String uuid = UUID.randomUUID().toString();
    return uuid + extension;
}
```

- `originalFilename`: 사용자가 업로드한 원본 파일명
- `UUID.randomUUID()`: 고유한 식별자 생성
- 확장자 유지하면서 이름만 변경

---

### 📥 2. 파일 업로드 Controller 예시

```java
@PostMapping("/upload")
public ResponseEntity<?> uploadImage(@RequestParam("file") MultipartFile file) throws IOException {
    String originalFilename = file.getOriginalFilename();
    String newFilename = generateFileName(originalFilename);

    Path savePath = Paths.get("C:/upload/images/" + newFilename);
    Files.copy(file.getInputStream(), savePath, StandardCopyOption.REPLACE_EXISTING);

    return ResponseEntity.ok("파일 업로드 완료: " + newFilename);
}
```

- `MultipartFile`로 파일을 받고
- 자동 생성된 이름으로 저장
- 저장 경로는 원하는 디렉토리로 설정 가능

---

### 🧼 3. 파일명 충돌 방지 + 보안 강화 팁

- **UUID + 날짜 조합**으로 더 안전하게 만들 수 있어요:
  ```java
  String newFilename = LocalDate.now() + "_" + UUID.randomUUID() + extension;
  ```
- 이미지 파일인지 검증하려면 MIME 타입 체크도 추가하세요:
  ```java
  if (!file.getContentType().startsWith("image")) {
      throw new IllegalArgumentException("이미지 파일만 업로드 가능합니다.");
  }
  ```

---

이 방식은 상품 이미지뿐 아니라 프로필 사진, 게시글 첨부 이미지 등에도 널리 사용됩니다. 혹시 AWS S3나 클라우드 저장소를 쓰고 있다면 방식이 조금 달라지니, 그 경우도 알려주시면 맞춤형으로 도와드릴게요!
