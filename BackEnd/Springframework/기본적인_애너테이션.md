# 스프링부트(Spring Boot) 애너테이션
> 스프링부트(Spring Boot) 프로젝트를 진행할 때 자주 사용되는 애너테이션들을 **중요도와 사용 빈도**에 따라 정리
> 이 목록은 **애플리케이션의 구조, 기능 구현, 설정**에 따라 달라질 수 있지만, 전반적으로 핵심적인 애너테이션들을 중심으로 구성

---

## 🥇 핵심 애너테이션 (필수적이고 가장 자주 사용됨)

| 애너테이션 | 설명 |
|------------|------|
| `@SpringBootApplication` | 스프링부트의 시작점. `@Configuration`, `@EnableAutoConfiguration`, `@ComponentScan`을 포함 |
| `@RestController` | RESTful 웹 서비스를 위한 컨트롤러. `@Controller` + `@ResponseBody` |
| `@RequestMapping` / `@GetMapping`, `@PostMapping` 등 | HTTP 요청을 처리하는 메서드에 매핑 |
| `@Autowired` | 의존성 주입(DI)을 위한 필드, 생성자, 메서드에 사용 |
| `@Component`, `@Service`, `@Repository` | 스프링 컨테이너에 빈으로 등록하기 위한 클래스 지정 |

---

## 🥈 비즈니스 로직 및 데이터 처리 관련

| 애너테이션 | 설명 |
|------------|------|
| `@Entity` | JPA에서 데이터베이스 테이블과 매핑되는 클래스 지정 |
| `@Id` | 기본 키 필드 지정 |
| `@GeneratedValue` | 기본 키 생성 전략 지정 |
| `@Table` | 테이블 이름 등 추가 설정 가능 |
| `@Column` | 컬럼 속성 지정 (nullable, length 등) |
| `@Transactional` | 트랜잭션 처리. 서비스나 DAO 계층에서 사용 |
| `@Query` | JPQL 또는 native SQL을 직접 작성할 때 사용 |

---

## 🥉 설정 및 보조 기능

| 애너테이션 | 설명 |
|------------|------|
| `@Configuration` | 자바 기반 설정 클래스 지정 |
| `@Bean` | 개발자가 직접 정의한 빈 등록 |
| `@Value` | application.properties 또는 yml에서 값 주입 |
| `@EnableJpaRepositories` | JPA 리포지토리 활성화 |
| `@EnableTransactionManagement` | 트랜잭션 관리 활성화 |
| `@PropertySource` | 외부 설정 파일 로딩 |

---

## 🧪 테스트 관련

| 애너테이션 | 설명 |
|------------|------|
| `@SpringBootTest` | 통합 테스트를 위한 애플리케이션 컨텍스트 로딩 |
| `@WebMvcTest` | 컨트롤러 테스트에 특화된 설정 |
| `@MockBean` | 테스트용으로 빈을 모킹할 때 사용 |

## 🧩 기타 유용한 애너테이션

## 자주 사용되는 **특정 기능별 애너테이션**을 정리
-  🔐보안(Spring Security),
-  🔑OAuth2 인증

---

## 🔐 Spring Security 관련 애너테이션

| 애너테이션 | 설명 |
|------------|------|
| `@EnableWebSecurity` | Spring Security 설정을 활성화하는 클래스에 사용 |
| `@Configuration` | 보안 설정 클래스를 자바 기반 설정으로 지정 |
| `@Bean` | 커스텀 필터, PasswordEncoder 등을 빈으로 등록 |
| `@AuthenticationPrincipal` | 현재 인증된 사용자 정보를 컨트롤러에서 주입받을 때 사용 |
| `@PreAuthorize("hasRole('ROLE_USER')")` | 메서드 실행 전에 권한 체크 |
| `@Secured("ROLE_ADMIN")` | 특정 역할을 가진 사용자만 접근 가능 |
| `@PermitAll`, `@DenyAll` | 접근 허용/거부 지정 (JSR-250 기반) |
| `@RolesAllowed("ROLE_MANAGER")` | 지정된 역할만 접근 가능 (JSR-250 기반) |

---

## 🔑 OAuth2 / JWT 인증 관련 애너테이션

| 애너테이션 | 설명 |
|------------|------|
| `@EnableAuthorizationServer` | OAuth2 인증 서버 설정 클래스에 사용 (Spring Security OAuth2 legacy) |
| `@EnableResourceServer` | 리소스 서버 설정 클래스에 사용 |
| `@EnableOAuth2Client` | OAuth2 클라이언트 기능 활성화 |
| `@RegisteredOAuth2AuthorizedClient` | 인증된 OAuth2 클라이언트 정보를 주입받을 때 사용 |
| `@AuthenticationPrincipal Jwt jwt` | JWT 기반 인증에서 사용자 정보 추출 |
| `@EnableMethodSecurity` | 메서드 수준 보안 활성화 (`@PreAuthorize`, `@PostAuthorize` 등 사용 가능) |

> 💡 최신 Spring Security에서는 `spring-security-oauth2` 대신 `spring-security-oauth2-client`, `spring-security-oauth2-resource-server` 등을 사용하며, 설정 방식이 조금 다릅니다.
