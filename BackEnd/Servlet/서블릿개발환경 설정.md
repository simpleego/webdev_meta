### 🛠️ 2. 개발 환경 설정 단계

#### ✅ JDK 11 설치
- [Oracle JDK 11 다운로드](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html) 또는 [OpenJDK 11 다운로드](https://jdk.java.net/archive/)
- 설치 후 환경 변수 설정:
  - `JAVA_HOME` → JDK 설치 경로
  - `Path` → `%JAVA_HOME%\bin`

#### ✅ Apache Tomcat 설치
- [Tomcat 공식 사이트](https://tomcat.apache.org/)에서 Tomcat 9 또는 10 다운로드
- 설치 후 환경 변수 설정:
  - `CATALINA_HOME` → Tomcat 설치 경로
  - `CLASSPATH` → `servlet-api.jar` 경로 추가 (예: `%CATALINA_HOME%\lib\servlet-api.jar`)

#### ✅ Eclipse IDE 설치
- [Eclipse 다운로드 페이지](https://www.eclipse.org/downloads/)
- **Eclipse IDE for Enterprise Java and Web Developers** 선택
- 버전은 JDK11과 호환이 되도록  4.18 이상을 선택
- 설치 후 Tomcat 연동:
  - `Window > Preferences > Server > Runtime Environments`에서 Tomcat 추가
  - 동적 웹 프로젝트 생성: `File > New > Dynamic Web Project`

### 📄 3. JSP/서블릿 예제 실행

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" %>
<html>
  <head><title>Hello JSP</title></head>
  <body>
    <h1>Hello, JSP!</h1>
  </body>
</html>
```

- 위 코드를 `Hello.jsp`로 저장 후 `http://localhost:8080/프로젝트명/Hello.jsp`에서 확인
