자바스크립트(JavaScript)와 자바(Java)는 언어 구조도 다르고, 이벤트 처리 방식도 꽤 다릅니다. 둘 다 “사용자의 행동에 반응한다”는 목적은 같지만, 접근 방법은 전혀 달라요. 아래에 비교해서 정리해봤어요:

---

### 📌 기본 개념 차이
| 항목             | 자바스크립트                              | 자바                                |
|------------------|--------------------------------------------|-------------------------------------|
| 실행 환경        | 웹 브라우저                                | 데스크톱 애플리케이션 (Swing, AWT 등) |
| 이벤트 모델      | 이벤트 기반 프로그래밍                     | 이벤트-리스너 기반 프로그래밍      |

---

### 🖱️ 이벤트 등록 방식

#### ✅ JavaScript
자바스크립트에서는 DOM 요소에 직접 이벤트를 등록할 수 있어요.

```javascript
document.getElementById("btn").addEventListener("click", function() {
  alert("버튼 클릭됨!");
});
```

- `addEventListener()`를 사용해서 원하는 이벤트를 지정
- 이벤트 핸들러를 익명 함수, 명명 함수 또는 외부 함수로 지정 가능
- HTML 속성(`onclick`, `onchange` 등)으로도 등록 가능하지만 권장되지 않음

#### ✅ Java (예: Swing UI)
자바에서는 이벤트를 감지하는 `Listener` 인터페이스를 구현하거나 익명 클래스로 처리해요.

```java
JButton btn = new JButton("클릭");
btn.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent e) {
        System.out.println("버튼 클릭됨!");
    }
});
```

- 이벤트 리스너 객체를 생성하여 `addActionListener()` 등에 등록
- 자바에서는 이벤트를 객체로 전달 (`ActionEvent` 등)
- 람다식 (`Java 8+`) 사용 가능해서 코드 간결화 가능

---

### ⚙️ 이벤트 흐름 방식

| 항목           | 자바스크립트                     | 자바                                  |
|----------------|----------------------------------|---------------------------------------|
| 이벤트 흐름     | 캡처링 단계 → 타깃 → 버블링 단계 | 콜백 메서드 호출 (버블링 없음)       |
| 이벤트 전달 방식 | 이벤트 객체 자동 전달 (`event`) | 이벤트 객체 수동 전달 (`ActionEvent`) |

- 자바스크립트는 **이벤트 버블링/캡처링**을 지원 → 복잡한 상위/하위 요소 간 제어 가능
- 자바는 단순 **리스너 구조**로 더 직관적이지만 유연성은 낮을 수 있음

---

### 🎯 정리하면…

| 공통점 | 차이점 |
|--------|--------|
| 사용자 인터랙션에 반응하는 구조 | 자바스크립트는 웹 중심, 자바는 GUI 앱 중심 |
| 이벤트 핸들러를 등록함 | 자바는 `Listener` 패턴, JS는 `addEventListener` |
| 이벤트 객체를 전달함 | JS는 버블링/캡처링 가능, 자바는 버블링 없음 |
