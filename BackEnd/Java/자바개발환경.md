# 자바 개발환경 설정
IntelliJ IDEA에서 자바 개발 환경 설정을 위해 JDK 설치 후, 시스템 환경 변수 설정과 IntelliJ IDEA 내에서 JDK 경로를 지정해야 합니다. 
## 1. JDK 설치
Java Development Kit(JDK)를 배포하는 주요 회사들은 다음과 같습니다
1. **Oracle** – Java의 원 개발사로, 상용 및 개인용 Oracle JDK를 제공합니다. [Oracle 공식 다운로드 페이지](https://www.oracle.com/kr/java/technologies/downloads/)에서 확인할 수 있어요.
2. **OpenJDK** – Java의 오픈소스 버전으로, 다양한 기업들이 이를 기반으로 자체 배포판을 제공합니다.
3. **Azul Systems** – *Zulu*라는 이름으로 OpenJDK 기반 JDK를 배포하며, 고성능 JVM인 *Zing*도 제공합니다.
4. **Amazon** – *Amazon Corretto*라는 이름으로 OpenJDK 기반 JDK를 배포하며, AWS 환경에 최적화되어 있습니다.
5. **Eclipse Foundation** – *Temurin*이라는 이름으로 AdoptOpenJDK의 후속 프로젝트를 운영하며, 다양한 플랫폼을 지원합니다.
6. **Red Hat** – OpenJDK 기반 JDK를 제공하며, 주로 엔터프라이즈 환경에서 사용됩니다.
7. **SAP** – SAP Machine이라는 이름으로 OpenJDK 기반 JDK를 배포합니다.
8. **BellSoft** – *Liberica JDK*라는 이름으로 다양한 플랫폼과 아키텍처를 지원하는 JDK를 제공합니다.
9. **IBM** – Semeru라는 이름으로 OpenJDK 기반 JDK를 배포합니다.

이 외에도 국내에서는 **진달래소프트**와 같은 기업이 Azul Systems와 협력하여 고성능 JDK 솔루션을 제공하고 있어요.
위의 사이트에서 원하는 JDK 버전을 다운로드하여 설치합니다.
설치 과정에서 JDK 설치 경로를 확인해 둡니다. 
## 2. 시스템 환경 변수 설정
- 환경 변수 정의
환경 변수란 위키피디아의 정의에 따르면 프로세스가 컴퓨터에서 동작하는 방식에 영향을 미치는, 동적인 값들의 모임이다.
- 환경 변수 확인 방법  
환경 변수는 다음 두 방법으로 확인할 수 있다.  
- 1. cmd에서의 set 명령어  
- 2. 내 PC >> 속성 >> 고급 시스템 설정 >> 고급 탭 >> 환경 변수  
1번 set 명령어는 확인하기 편하고 편집도 가능하지만 편집하려면 2번이 편하다.

- JAVA_HOME 설정:  
시스템 환경 변수 편집 창을 열고, 새로 만들기를 클릭합니다.   
- 변수 이름: JAVA_HOME   
- 변수 값: JDK 설치 경로 (예: C:\Program Files\Java\jdk-21)  
- Path 설정:  
시스템 환경 변수 편집 창에서 Path 변수를 선택하고 편집을 클릭합니다.  
새로 만들기를 클릭하고 %JAVA_HOME%\bin을 입력합니다.

##  3. IntelliJ IDEA 설정:
Project SDK 설정:  
IntelliJ IDEA를 실행하고 프로젝트를 열거나 새 프로젝트를 생성합니다.  
File > Project Structure > Project로 이동합니다.  
Project SDK 드롭다운 메뉴에서 설치한 JDK 버전을 선택합니다.  
Module SDK 설정 (필요한 경우):  
Modules 탭에서 각 모듈의 SDK를 설정합니다.  
Dependencies 탭에서 필요한 라이브러리를 추가합니다.   

##  4. IntelliJ IDEA에서 Java 코드 작성 및 실행:   
Java 파일을 생성하고 코드를 작성합니다.  
Run 메뉴에서 실행할 파일을 선택하여 코드를 실행합니다.   

## 5참고사항:  
IntelliJ IDEA는 기본적으로 Maven을 사용하므로, 시스템에 설치된 Maven 경로를 지정해야 할 수도 있습니다.  
IntelliJ IDEA 설정에서 테마, 글꼴, 단축키 등을 변경하여 개발 환경을 개인 설정에 맞게 커스터마이징할 수 있습니다.
