🚗 추가기능
## 자동차의 **종류(type)**, **연료(fuel)**, 그리고 **크루즈 기능(cruise mode)**을 포함해서 더욱 현실적인 시뮬레이션을 만들어볼게요.

---

### 🏗️ 전체 구조 설계 변경 요약

| 항목       | 설명                                                               |
|------------|--------------------------------------------------------------------|
| `Car`       | 자동차 종류, 연료 타입, 크루즈 모드 포함                          |
| `Driver`    | 자동차의 기능을 운전자 관점에서 제어                               |
| `Main`      | 전체 흐름 테스트                                                  |

---

### 🚙 `Car` 클래스 확장
```java
public class Car {
    private String type;
    private String fuelType;
    private boolean engineOn = false;
    private boolean cruiseOn = false;
    private int speed = 0;

    public Car(String type, String fuelType) {
        this.type = type;
        this.fuelType = fuelType;
    }

    public void startEngine() {
        engineOn = true;
        System.out.println("🔑 " + type + " 시동이 걸렸습니다. 연료 타입: " + fuelType);
    }

    public void stopEngine() {
        engineOn = false;
        cruiseOn = false;
        speed = 0;
        System.out.println("⛔ " + type + " 시동이 꺼졌습니다.");
    }

    public void accelerate() {
        if (engineOn) {
            speed += 10;
            System.out.println("🏎️ 가속 중... 현재 속도: " + speed + "km/h");
        } else {
            System.out.println("🚫 시동이 꺼져 있어 가속할 수 없습니다.");
        }
    }

    public void brake() {
        if (speed > 0) {
            speed -= 10;
            System.out.println("🅿️ 감속 중... 현재 속도: " + speed + "km/h");
        } else {
            System.out.println("🛑 이미 정지 상태입니다.");
        }
    }

    public void activateCruise() {
        if (engineOn && speed >= 40) {
            cruiseOn = true;
            System.out.println("🧭 크루즈 모드 활성화! 일정 속도로 주행 중...");
        } else {
            System.out.println("⚠️ 크루즈 모드를 켜려면 시동이 켜져 있고 속도가 40km/h 이상이어야 합니다.");
        }
    }

    public void deactivateCruise() {
        cruiseOn = false;
        System.out.println("🔧 크루즈 모드 해제됨.");
    }
}
```

---

### 🧑‍✈️ `Driver` 클래스 업데이트
```java
public class Driver {
    private String name;
    private Car car;

    public Driver(String name, Car car) {
        this.name = name;
        this.car = car;
    }

    public void driveWithCruise() {
        System.out.println("\n👤 " + name + "이(가) " + car.getClass().getSimpleName() + "를 운전합니다.");

        car.startEngine();
        car.accelerate();
        car.accelerate();
        car.accelerate(); // 속도 30
        car.accelerate(); // 속도 40, 크루즈 가능
        car.activateCruise();
        car.brake();
        car.deactivateCruise();
        car.stopEngine();

        System.out.println("🚦 운전 종료\n");
    }
}
```

---

### 🧪 실행 예시
```java
public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("세단", "가솔린");
        Driver driver = new Driver("홍길동", myCar);
        driver.driveWithCruise();
    }
}
```

이제 자동차 종류와 연료는 초기화 시점에 정해지고, **크루즈 모드**는 속도 조건이 충족되었을 때만 사용할 수 있어요. 더 발전시켜서 전기차 충전 상태, 하이브리드 모드, 자율주행 등도 넣어볼 수 있어요. 🚘💡
