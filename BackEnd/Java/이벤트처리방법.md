자바 Swing 컴포넌트마다 이벤트를 바인딩하는 방식
---

🖱️ **버튼 (JButton)**
- **이벤트 리스너**: `ActionListener`
```java
button.addActionListener(e -> System.out.println("버튼이 클릭되었습니다."));
```

---

📝 **텍스트 필드 (JTextField)**
- **이벤트 리스너**: `ActionListener` (엔터 키 입력 시)
```java
textField.addActionListener(e -> System.out.println("텍스트 입력 완료: " + textField.getText()));
```
- 또는 **KeyBindings**로 키 입력 이벤트 제어 가능

---

📋 **체크박스 (JCheckBox)**
- **이벤트 리스너**: `ItemListener`
```java
checkBox.addItemListener(e -> {
    if (e.getStateChange() == ItemEvent.SELECTED)
        System.out.println("선택됨");
});
```

---

🔘 **라디오 버튼 (JRadioButton)**
- **이벤트 리스너**: `ActionListener`
```java
radioButton.addActionListener(e -> System.out.println("라디오 버튼 선택됨"));
```

---

📂 **콤보 박스 (JComboBox)**
- **이벤트 리스너**: `ActionListener`, `ItemListener`
```java
comboBox.addActionListener(e -> System.out.println("선택된 항목: " + comboBox.getSelectedItem()));
```

---

📄 **리스트 (JList)**
- **이벤트 리스너**: `ListSelectionListener`
```java
list.addListSelectionListener(e -> {
    if (!e.getValueIsAdjusting()) {
        System.out.println("선택: " + list.getSelectedValue());
    }
});
```

---

📅 **슬라이더 (JSlider)**
- **이벤트 리스너**: `ChangeListener`
```java
slider.addChangeListener(e -> System.out.println("값 변경됨: " + slider.getValue()));
```
