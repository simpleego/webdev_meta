# 자바 클래스 기초과정 과제 프로젝트

## 프로젝트 1: 학생 성적 관리 시스템

### 클래스 다이어그램
```
┌─────────────────────┐
│      Student        │
├─────────────────────┤
│ - name: String      │
│ - studentId: String │
│ - koreanScore: int  │
│ - englishScore: int │
│ - mathScore: int    │
├─────────────────────┤
│ + Student(name, id) │
│ + getName(): String │
│ + setName(String)   │
│ + getStudentId()    │
│ + setKoreanScore()  │
│ + setEnglishScore() │
│ + setMathScore()    │
│ + getAverage()      │
│ + getGrade(): char  │
│ + displayInfo()     │
└─────────────────────┘
```

### 요구사항
- 학생 정보(이름, 학번) 입력
- 과목별 점수 입력 (국어, 영어, 수학)
- 평균 계산 (소수점 둘째 자리까지)
- 등급 계산 (A: 90-100, B: 80-89, C: 70-79, D: 60-69, F: 0-59)
- 학생 정보 출력

### 핵심 학습 목표
- 생성자 활용
- getter/setter 메서드 구현
- 계산 로직 구현
- 조건문 활용

┌─────────────────────┐    ┌─────────────────────┐    ┌─────────────────────┐
│      Product        │    │    ShoppingCart     │    │     CartItem        │

│ - name: String      │    │ - items: CartItem[] │    │ - product: Product  │

│ - stock: int        │    ├─────────────────────┤    ├─────────────────────┤
│ - category: String  │┌───│ + addItem(Product,  │┌───│ + CartItem(product, │
├─────────────────────┤│   │   quantity)         ││   │   quantity)         │
│ + Product(name,     ││   │ + removeItem(name)  ││   │ + getProduct()      │
│   price, stock,     ││   │ + updateQuantity()  ││   │ + getQuantity()     │
│   category)         ││   │ + getTotalPrice()   ││   │ + setQuantity(int)  │

- 결제 처리 (재고 감소)

### 핵심 학습 목표

## 각 프로젝트별 제출 요구사항

### 1. 소스 코드
- 각 클래스별 .java 파일
- main 메서드가 포함된 실행 클래스
- 주석 처리된 코드 (클래스, 메서드 설명)

### 2. 실행 결과
- 콘솔 출력 결과 스크린샷
- 각 기능별 테스트 결과

### 3. 설계 문서
- 클래스 다이어그램
- 주요 메서드 설명
- 프로그램 실행 흐름

### 4. 평가 기준
- 객체지향 설계 원칙 준수 (30%)
- 기능 구현 완성도 (40%)
- 코드 품질 및 가독성 (20%)
- 예외 처리 및 검증 (10%)
