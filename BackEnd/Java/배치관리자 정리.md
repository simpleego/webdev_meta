🧭 자바 스윙에서 **배치관리자(LayoutManager)**는 컴포넌트의 위치와 크기를 자동으로 조절해주는 도구로서
각각의 배치관리자는 고유한 방식으로 컴포넌트를 배치하며, 상황에 따라 적절한 것을 선택해야 한다.

---

### 📋 주요 배치관리자 비교표

| 배치관리자       | 특징 요약                                                                 | 배치 방식 예시                          |
|------------------|---------------------------------------------------------------------------|------------------------------------------|
| **FlowLayout**   | 왼쪽 → 오른쪽으로 컴포넌트 배치, 공간 부족 시 다음 줄로 이동             | `new FlowLayout(FlowLayout.LEFT, 10, 20)` |
| **BorderLayout** | 5개 영역(NORTH, SOUTH, EAST, WEST, CENTER)에 컴포넌트 배치                | `add(comp, BorderLayout.NORTH)`          |
| **GridLayout**   | 행과 열로 나눠 균등한 크기로 컴포넌트 배치                                | `new GridLayout(2, 3, 5, 5)`              |
| **GridBagLayout**| 유연한 격자 배치, 셀 병합 및 크기 조절 가능 (복잡하지만 강력함)           | `GridBagConstraints` 활용                |
| **CardLayout**   | 여러 컴포넌트를 겹쳐놓고 하나씩 보여줌 (탭/슬라이드 UI에 적합)             | `cardLayout.show(container, "card1")`    |
| **BoxLayout**    | 수직 또는 수평 방향으로 컴포넌트 배치                                     | `new BoxLayout(panel, BoxLayout.Y_AXIS)` |
| **null layout**  | 배치관리자 없이 수동으로 위치/크기 지정 (`setBounds()` 사용)              | `panel.setLayout(null)`                  |

---

### 🧩 각 배치관리자의 특징 자세히 보기

#### 1. **FlowLayout**
- 컴포넌트를 **왼쪽에서 오른쪽으로** 배치
- 공간이 부족하면 자동으로 **다음 줄로 이동**
- 정렬 방식: `LEFT`, `CENTER`, `RIGHT`
- 간단한 UI에 적합

#### 2. **BorderLayout**
- 컨테이너를 **5개 영역**으로 나눔
  - `NORTH`, `SOUTH`: 가로 방향 확장
  - `EAST`, `WEST`: 세로 방향 확장
  - `CENTER`: 남은 공간 모두 차지
- 각 영역에 **하나의 컴포넌트만** 배치 가능

#### 3. **GridLayout**
- **행과 열**로 나눠 모든 셀에 **동일한 크기**로 컴포넌트 배치
- 셀 간 간격 설정 가능 (`hgap`, `vgap`)
- 계산기 UI처럼 균등한 배치에 적합

#### 4. **GridBagLayout**
- `GridLayout`보다 **유연한 배치** 가능
- 셀 병합, 크기 비율 조절 등 고급 기능 제공
- 복잡한 UI에 적합하지만 설정이 까다로움

#### 5. **CardLayout**
- 여러 컴포넌트를 **겹쳐놓고 하나씩 보여줌**
- 탭, 슬라이드, 단계별 화면 전환 등에 유용
- `show()` 메서드로 원하는 카드 표시

#### 6. **BoxLayout**
- 컴포넌트를 **수직(Y_AXIS)** 또는 **수평(X_AXIS)** 방향으로 정렬
- `Box.createRigidArea()`나 `Box.createVerticalStrut()`로 간격 조절 가능

#### 7. **null layout**
- 배치관리자 없이 **절대 위치 지정**
- `setBounds(x, y, width, height)`로 직접 위치/크기 설정
- 유연하지만 **반응형 UI에 불리**하고 유지보수가 어려움
