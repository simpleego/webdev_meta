# 이메일 인증 회원가입 

## 📁 파일 구조
- **EmailVerificationController**: 회원가입 페이지 및 인증 API 처리
- **EmailService**: 인증 코드 생성 및 이메일 발송
- **signup.html**: 간단한 회원가입 화면
- **application.properties**: 이메일 설정
- **pom.xml**: 필요한 의존성

## 🔄 동작 흐름
1. 사용자가 이메일 입력 후 "인증코드 전송" 클릭
2. 6자리 랜덤 코드가 이메일로 발송
3. 받은 코드를 입력하고 "인증하기" 클릭
4. 인증 성공 시 회원가입 버튼 활성화
5. 회원가입 완료

## ⚙️ 설정 방법

**Gmail 사용 시:**
1. Gmail 2단계 인증 활성화
2. 앱 비밀번호 생성 (Google 계정 > 보안 > 앱 비밀번호)
3. `application.properties`에 이메일과 앱 비밀번호 입력

**파일 위치:**
- `signup.html` → `src/main/resources/templates/`
- 나머지 Java 파일들은 해당 패키지에 배치

접속 URL: `http://localhost:8080/signup`
