# LMS(학습 관리 시스템) 요구사항 명세서

## 참고사이트
> https://wikidocs.net/291486

## 1. 문서 개요

### 1.1 프로젝트 개요
- **프로젝트 명**: LMS(Learning Management System)
- **목적**: 온라인 학습 환경 제공, 교육 과정 관리, 학습 진행 상황 추적
- **대상 사용자**: 교육 기관, 기업 교육 담당자, 학습자

### 1.2 문서 목적
본 문서는 LMS 개발을 위한 기능적/비기능적 요구사항을 정의합니다.

---

## 2. 시스템 개요

### 2.1 시스템 아키텍처
- 웹 기반 애플리케이션
- 반응형 웹 디자인 (모바일/태블릿/데스크탑 지원)
- 클라우드 기반 호스팅

### 2.2 주요 기능 범위
- 사용자 관리
- 강의 관리
- 수강 관리
- 평가 및 시험
- 보고서 및 분석

---

## 3. 기능적 요구사항

### 3.1 사용자 관리

#### 3.1.1 사용자 등급별 권한
| 사용자 유형 | 권한 |
|------------|------|
| 관리자 | 시스템 전체 관리, 모든 기능 접근 |
| 교수자 | 강의 생성/관리, 성적 평가, 학습자 관리 |
| 학습자 | 강의 수강, 과제 제출, 시험 응시 |

#### 3.1.2 사용자 등록 및 인증
- **FR-001**: 이메일 기반 회원가입
- **FR-002**: 소셜 로그인 (Google, Facebook) 지원
- **FR-003**: 비밀번호 찾기 및 재설정
- **FR-004**: 이메일 인증
- **FR-005**: 역할 기반 접근 제어

### 3.2 강의 관리

#### 3.2.1 강의 생성 및 관리
- **FR-101**: 강의 개설 (제목, 설명, 카테고리, 썸네일)
- **FR-102**: 강의 구성 요소 관리 (섹션, 강의, 자료)
- **FR-103**: 다중 미디어 콘텐츠 지원 (동영상, PDF, PPT)
- **FR-104**: 강의 공개/비공개 설정
- **FR-105**: 강의 수정 및 삭제

#### 3.2.2 콘텐츠 관리
- **FR-106**: 동영상 스트리밍 지원
- **FR-107**: 진행률 자동 저장
- **FR-108**: 다운로드 가능한 자료 관리
- **FR-109**: 콘텐츠 버전 관리

### 3.3 수강 관리

#### 3.3.1 수강 신청 및 진행
- **FR-201**: 강의 검색 및 수강 신청
- **FR-202**: 수강 진행률 추적
- **FR-203**: 학습 일시정지 및 재개
- **FR-204**: 수강 증명서 발급
- **FR-205**: 수강 취소 및 환불

#### 3.3.2 학습자 대시보드
- **FR-206**: 진행 중인 강의 목록
- **FR-207**: 최근 학습 활동
- **FR-208**: 완료한 강의 목록
- **FR-209**: 학습 통계

### 3.4 평가 및 시험

#### 3.4.1 시험 관리
- **FR-301**: 다양한 유형의 문제 출제 (객관식, 주관식, 서술형)
- **FR-302**: 시험 시간 제한 설정
- **FR-303**: 자동 채점 기능
- **FR-304**: 시험 결과 분석
- **FR-305**: 부정행위 방지 (화면 전환 감지)

#### 3.4.2 과제 관리
- **FR-306**: 과제 제출 및 평가
- **FR-307**: 파일 업로드 지원
- **FR-308**: 피드백 기능
- **FR-309**: 점수 부여 및 통계

### 3.5 커뮤니케이션

#### 3.5.1 토론 및 Q&A
- **FR-401**: 강의별 Q&A 게시판
- **FR-402**: 실시간 채팅
- **FR-403**: 공지사항 발송
- **FR-404**: 이메일 알림

#### 3.5.2 협업 도구
- **FR-405**: 그룹 프로젝트 관리
- **FR-406**: 파일 공유
- **FR-407**: 캘린더 통합

### 3.6 보고서 및 분석

#### 3.6.1 학습 분석
- **FR-501**: 학습자 진행률 보고서
- **FR-502**: 성적 분포 분석
- **FR-503**: 강의 만족도 조사
- **FR-504**: 학습 패턴 분석

#### 3.6.2 관리자 보고서
- **FR-505**: 수익 현황
- **FR-506**: 사용자 활동 로그
- **FR-507**: 시스템 사용 통계

## 4. 비기능적 요구사항

### 4.1 성능 요구사항
- **NFR-001**: 동시 사용자 1,000명 지원
- **NFR-002**: 페이지 로딩 시간 3초 이내
- **NFR-003**: 99.5% 가용성 보장
- **NFR-004**: 데이터 백업 및 복구 기능

### 4.2 보안 요구사항
- **NFR-101**: 개인정보 암호화 저장
- **NFR-102**: SSL/TLS 적용
- **NFR-103**: 정기적인 보안 감사
- **NFR-104**: 접근 로그 관리

### 4.3 사용성 요구사항
- **NFR-201**: 직관적인 사용자 인터페이스
- **NFR-202**: 반응형 웹 디자인
- **NFR-203**: WCAG 2.1 접근성 준수
- **NFR-204**: 다국어 지원 (한국어, 영어)

### 4.4 호환성 요구사항
- **NFR-301**: Chrome, Safari, Firefox, Edge 최신 2버전 지원
- **NFR-302**: iOS, Android 모바일 브라우저 지원
- **NFR-303**: 다양한 해상도 대응

---

## 5. 시스템 통합 요구사항

### 5.1 외부 시스템 연동
- **IR-001**: 결제 시스템 연동 (PG사)
- **IR-002**: 이메일 서비스 연동
- **IR-003**: 클라우드 스토리지 연동
- **IR-004**: SSO(Single Sign-On) 지원

### 5.2 API 요구사항
- **IR-101**: RESTful API 제공
- **IR-102**: Webhook 지원
- **IR-103**: 타 시스템과의 데이터 연동

---

## 6. 데이터 관리 요구사항

### 6.1 데이터 저장
- **DR-001**: 사용자 데이터 보관 기간: 회원 탈퇴 시까지
- **DR-002**: 학습 데이터 보관 기간: 5년
- **DR-003**: 정기 데이터 백업

### 6.2 데이터 마이그레이션
- **DR-101**: 기존 시스템 데이터 이관 기능
- **DR-102**: 대량 데이터 일괄 처리

- **MR-003**: 성능 지표 대시보드

## 8. 제약 조건

### 8.1 기술적 제약
- 클라우드 인프라 사용
- 오픈소스 기술 스택 우선 적용

### 8.2 비즈니스 제약
- 6개월 내 1차 개발 완료

- 기존 인프라와의 호환성

## 9. 용어 정의

| 용어 | 설명 |
|------|------|
| LMS | Learning Management System (학습 관리 시스템) |
| 관리자 | 시스템 전체를 관리하는 최고 권한자 |
| 교수자 | 강의를 생성하고 관리하는 사용자 |
| 학습자 | 강의를 수강하는 사용자 |
| 콘텐츠 | 강의를 구성하는 학습 자료 |
