# 스토리보드
## LMS 프로젝트 기본 기능 스토리보드

LMS(학습 관리 시스템) 프로젝트의 가장 핵심적인 3가지 기능을 기준으로 사용자(학습자) 관점의 간단한 스토리보드를 작성

**선정된 3가지 핵심 기능:**

1.  **수강 중인 강의 목록 조회**: 로그인 후 자신이 수강하는 모든 강의를 한눈에 보는 기능
2.  **강의 상세 및 회차별 학습자료 확인**: 특정 강의에 접속하여 주차별/회차별 강의 목록을 보는 기능
3.  **동영상 강의 시청 및 학습 완료 처리**: 강의를 시청하고 학습 진도율을 업데이트하는 기능

-----

### Storyboard \#1: 수강 중인 강의 목록 조회

| **기능 명** | 수강 중인 강의 목록 조회 (내 강의실) |
| :--- | :--- |
| **사용자** | 학습자 (Student) |
| **목표** | 자신이 수강 신청한 모든 강의를 한눈에 확인하고, 원하는 강의의 상세 페이지로 이동한다. |
| **주요 시나리오** | 1. 학습자가 시스템에 로그인한다.\<br\>2. 메인 화면 또는 '내 강의실' 메뉴로 이동한다.\<br\>3. 현재 수강 중인 강의들이 카드 형태로 나열된다.\<br\>4. 각 카드에는 강의명, 교수자명, 현재 진도율이 표시된다.\<br\>5. 학습자가 특정 강의의 '강의실 입장' 버튼을 클릭한다. |
| **화면 구성 요소** | \<ul\>\<li\>**헤더**: 로고, 내 정보, 로그아웃 버튼\</li\>\<li\>**페이지 제목**: "내 강의실" 또는 "My Courses"\</li\>\<li\>**강의 목록 영역**:\</li\>\<ul\>\<li\>**강의 카드 (반복)**:\</li\>\<ul\>\<li\>강의 대표 이미지 (썸네일)\</li\>\<li\>강의명 (예: "데이터베이스 개론")\</li\>\<li\>담당 교수자명 (예: "김개발 교수")\</li\>\<li\>**진도율 표시 막대 (Progress Bar)** (예: "75% 수강")\</li\>\<li\>'강의실 입장' 버튼\</li\>\</ul\>\</ul\>\</li\>\</ul\> |
| **비고** | - 진도율을 시각적으로 보여주어 학습자에게 학습 동기를 부여할 수 있다.\<br\>- 강의가 없는 경우 "수강 중인 강의가 없습니다."라는 안내 메시지를 표시한다. |

### Storyboard \#2: 강의 상세 및 회차별 학습자료 확인

| **기능 명** | 강의 상세 및 회차별 학습자료 확인 |
| :--- | :--- |
| **사용자** | 학습자 (Student) |
| **목표** | 선택한 강의의 전체 커리큘럼(회차별 목록)을 확인하고, 원하는 회차의 학습을 시작한다. |
| **주요 시나리오** | 1. '내 강의실'에서 특정 강의를 클릭하여 상세 페이지로 진입한다.\<br\>2. 화면 좌측에는 강의 개요, 공지사항, Q\&A 메뉴가 표시된다.\<br\>3. 화면 중앙에는 주차별 또는 회차별 강의 목록이 순서대로 나열된다.\<br\>4. 각 회차별로 강의 제목, 영상 길이, 학습 상태('수강 완료', '수강 전')가 표시된다.\<br\>5. 학습자가 원하는 회차(예: "1주차: 데이터베이스의 이해")를 클릭한다. |
| **화면 구성 요소** | \<ul\>\<li\>**강의 정보 패널 (좌측/상단)**:\</li\>\<ul\>\<li\>강의명, 교수자 정보\</li\>\<li\>강의 목표 및 소개\</li\>\<li\>'공지사항', 'Q\&A' 바로가기 버튼\</li\>\</ul\>\<li\>**회차별 강의 목록 (중앙)**:\</li\>\<ul\>\<li\>**섹션 제목** (예: "1주차: 데이터베이스 소개")\</li\>\<li\>**강의 항목 (반복)**:\</li\>\<ul\>\<li\>회차 번호 및 강의 제목 (예: "1-1. 데이터베이스란?")\</li\>\<li\>강의 시간 (예: "25:30")\</li\>\<li\>**학습 상태 아이콘** (예: 체크 표시 V, 미시청 아이콘)\</li\>\<li\>학습 자료 다운로드 아이콘 (있는 경우)\</li\>\</ul\>\</ul\>\</li\>\</ul\> |
| **비고** | - 학습 상태를 명확히 표시하여 학습자가 어디까지 수강했는지 쉽게 파악할 수 있도록 한다.\<br\>- 각 회차를 클릭하면 아래 3번 스토리보드의 '동영상 강의 시청' 화면으로 이동한다. |

### Storyboard \#3: 동영상 강의 시청 및 학습 완료 처리

| **기능 명** | 동영상 강의 시청 및 학습 완료 처리 |
| :--- | :--- |
| **사용자** | 학습자 (Student) |
| **목표** | 동영상 강의를 시청하고, 시스템이 자동으로 학습 상태를 '수강 완료'로 변경해주는 것을 확인한다. |
| **주요 시나리오** | 1. 강의 상세 페이지에서 특정 회차를 클릭한다.\<br\>2. 동영상 플레이어가 포함된 학습 페이지가 나타난다.\<br\>3. 학습자는 '재생' 버튼을 눌러 강의를 시청한다.\<br\>4. (시스템) 영상 시청 시간이 전체의 90%를 넘어가면 해당 회차의 학습 상태를 '수강 완료'로 자동 변경한다.\<br\>5. 영상 시청 후 '다음 강의' 버튼을 눌러 바로 다음 회차 학습을 이어간다. |
| **화면 구성 요소** | \<ul\>\<li\>**페이지 제목**: 현재 수강 중인 회차의 제목 (예: "1-1. 데이터베이스란?")\</li\>\<li\>**동영상 플레이어**:\</li\>\<ul\>\<li\>재생/일시정지, 볼륨 조절, 전체 화면 기능\</li\>\<li\>재생 속도 조절 기능 (0.8x, 1.0x, 1.5x 등)\</li\>\</ul\>\<li\>**부가 기능 버튼**:\</li\>\<ul\>\<li\>'학습 자료 다운로드' 버튼\</li\>\<li\>'질문하기' 버튼\</li\>\</ul\>\<li\>**네비게이션**:\</li\>\<ul\>\<li\>'이전 강의', '다음 강의' 버튼\</li\>\<li\>전체 강의 목록을 볼 수 있는 사이드바 또는 드롭다운 메뉴\</li\>\</ul\>\</li\>\</ul\> |
| **비고** | - 학습 완료 처리 기준(예: 시청 시간 90% 이상)은 기획 단계에서 명확히 정의해야 한다.\<br\>- 학습자가 수동으로 '학습 완료' 버튼을 누르는 방식을 추가로 고려할 수 있다. |
