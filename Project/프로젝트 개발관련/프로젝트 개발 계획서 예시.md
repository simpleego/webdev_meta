# 프로젝트 개발 계획서 예시
---

## ✅ 1. 프로젝트 목표 및 범위 정의

**템플릿 예시:**

- 프로젝트명: [예: "동네 맛집 공유 플랫폼"]
- 목적:  
  > 지역 주민들이 직접 추천하는 맛집 정보를 공유하고 검색할 수 있는 커뮤니티 플랫폼 구축
- 주요 기능:  
  - 맛집 등록 및 리뷰 작성  
  - 지도 기반 맛집 검색  
  - 사용자 프로필 및 활동 내역  
- 비기능 요구사항:  
  - 반응형 웹 디자인  
  - 로그인/회원가입 기능  
  - 데이터 보안 및 접근 제어

## 👥 2. 팀 구성 및 역할 분담

**템플릿 예시:**

| 이름     | 역할               | 주요 업무                          |
|----------|--------------------|-------------------------------------|
| 김민수   | PM (프로젝트 매니저) | 일정 관리, 회의 주관, 문서 정리     |
| 이지은   | 프론트엔드 개발자   | React 기반 UI 개발, 페이지 구성     |
| 박종천   | 백엔드 개발자       | API 개발, DB 설계 및 서버 구축      |
| 최유리   | 디자이너            | 와이어프레임, UI/UX 디자인         |
| 정우성   | QA/테스터           | 기능 테스트, 버그 리포트 및 개선안 제안 |

**협업 도구 추천:**
- GitHub (코드 관리)
- Notion (문서 및 회의록)
- Trello (작업 보드)
- Slack (실시간 커뮤니케이션)

## 🧩 3. 기술 스택 결정

**예시 스택:**

| 영역       | 기술 선택 예시         |
|------------|------------------------|
| 프론트엔드 | React, Tailwind CSS    |
| 백엔드     | Node.js + Express      |
| DB         | MongoDB (NoSQL)        |
| 인증       | JWT 기반 인증          |
| 배포       | Vercel (프론트), Render (백엔드) |

**선정 기준:**
- 팀원 경험
- 학습 곡선
- 커뮤니티 지원
- 확장성

## 📐 4. 기획 및 설계

**템플릿 예시:**

- 와이어프레임 도구: Figma, Adobe XD  
- 페이지 구성:  
  - 홈 화면  
  - 맛집 리스트 페이지  
  - 맛집 상세 페이지  
  - 리뷰 작성 페이지  
  - 마이페이지

- API 명세 예시:

```plaintext
GET /restaurants
→ 맛집 리스트 반환

POST /restaurants
→ 맛집 등록 (인증 필요)

GET /restaurants/:id
→ 특정 맛집 상세 정보

POST /reviews
→ 리뷰 작성 (인증 필요)
```

## 🛠️ 5. 개발 환경 세팅

**템플릿 예시:**

- Git 브랜치 전략:  
  - `main`: 배포용  
  - `dev`: 개발 통합  
  - `feature/xxx`: 기능별 브랜치  
- 코드 컨벤션: ESLint + Prettier 설정  
- CI/CD: GitHub Actions로 자동 테스트 및 배포  
- 환경 변수 관리: `.env` 파일 사용, `.gitignore`에 포함

## 📅 6. 일정 계획 및 마일스톤 설정

**예시 일정표:**

| 기간         | 작업 내용                      |
|--------------|-------------------------------|
| 1주차        | 기획 회의, 역할 분담, 기술 스택 결정 |
| 2~3주차      | 와이어프레임 및 API 설계, 환경 세팅 |
| 4~6주차      | 기능 개발 (프론트/백엔드 병행)     |
| 7주차        | 통합 테스트 및 버그 수정           |
| 8주차        | 최종 배포 및 발표 자료 준비        |

**리스크 관리 예시:**
- 일정 지연 → 매주 회고 및 조정  
- 기술 난이도 → 학습 세션 운영  
- 커뮤니케이션 오류 → 매일 스탠드업 미팅
