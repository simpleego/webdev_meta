# 와이어프레임
> LMS 프로젝트 개발에 필요한 핵심 화면 4가지에 대한 기본 와이어프레임을 제시

와이어프레임은 색상이나 디자인 요소를 배제하고 **화면의 구조, 요소 배치, 기능**에만 집중한 '설계도'입니다.

## 와이어프레임 참조
https://www.behance.net/gallery/57482845/Learning-Management-System-Wire-frames

-----

### \#\# 1. 로그인 페이지 (Login Page)

모든 사용자가 시스템에 접근하기 위한 첫 관문입니다. 간결하고 명확한 구성이 중요합니다.

  * **주요 구성 요소**:
      * 서비스 로고
      * 아이디/비밀번호 입력 필드
      * 로그인 버튼
      * 아이디/비밀번호 찾기, 회원가입 링크

| [ 서비스 로고 ] |
| :--- |
| **로그인** |
| [ 아이디 입력창 ] |
| [ 비밀번호 입력창 ] |
| [ 로그인 버튼 ] |
| 아이디/비밀번호 찾기 | 회원가입 |

-----

### \#\# 2. 대시보드 / 내 강의실 (Dashboard / My Courses)

로그인 후 학습자가 가장 먼저 보게 될 화면으로, 수강 중인 모든 강의 목록을 보여줍니다.

  * **주요 구성 요소**:
      * 헤더 (로고, 내 정보, 로그아웃)
      * 페이지 타이틀 ("내 강의실")
      * 강의 목록 (카드 형태)
          * 강의 썸네일 이미지
          * 강의명, 교수자명
          * 진도율 (Progress Bar)
          * 강의실 입장 버튼

| [ 로고 ] [ 내 정보 / 로그아웃 ] |
| :--- |
| **내 강의실** |
| --- |
| **[강의 썸네일]**\<br\>데이터베이스 개론\<br\>김개발 교수\<br\>[ 진도율 75% ]\<br\>[ 강의실 입장 ] | **[강의 썸네일]**\<br\>알고리즘 기초\<br\>이코딩 교수\<br\>[ 진도율 30% ]\<br\>[ 강의실 입장 ] |
| **[강의 썸네일]**\<br\>...\<br\>...\<br\>...\<br\>... | **[강의 썸네일]**\<br\>...\<br\>...\<br\>...\<br\>... |

### \#\# 3. 강의 상세 페이지 (학습 목차)

특정 강의의 전체 커리큘럼을 보여주는 화면입니다. 학습자는 여기서 원하는 회차의 강의를 선택합니다.

  * **주요 구성 요소**:
      * 강의 정보 (강의명, 소개)
      * 탭 메뉴 (강의 목차, 공지사항, Q\&A)
      * 회차별 강의 목록
          * 회차 번호 및 제목
          * 강의 시간
          * 학습 상태 (수강 완료 V / 미수강)

| **데이터베이스 개론** - 김개발 교수 |
| :--- |
| [ 강의 목차 ] [ 공지사항 ] [ Q\&A ] |
| --- |
| **▶ 1주차: 데이터베이스의 이해** |
| [ V ] 1-1. 데이터베이스란 무엇인가? (25:30) |
| [  ] 1-2. 관계형 데이터베이스 모델 (30:10) |
| **▶ 2주차: SQL 기초** |
| [  ] 2-1. SELECT 문법 기초 (45:00) |

### \#\# 4. 강의 시청 페이지 (Video Player)

실제 학습이 이루어지는 가장 중요한 화면입니다.

  * **주요 구성 요소**:
      * 현재 강의 제목
      * 동영상 플레이어
      * 부가 기능 (학습 자료 다운로드, 질문하기)
      * 강의 이동 버튼 (이전/다음 강의)
      * 전체 강의 목록 사이드바

| **1-1. 데이터베이스란 무엇인가?** | [ 전체 목차 보기 ] |
| :--- | :--- |
| [ **동영상 플레이어 영역** ] | **▶ 1주차**\<br\>[V] 1-1. 강의\<br\>[ ] 1-2. 강의 |
| [ 재생/일시정지 ] [ 음량 ] [ 속도 ] [ 전체화면 ] | **▶ 2주차**\<br\>[ ] 2-1. 강의 |
| [ 학습자료 다운로드 ] [ 질문하기 ] | ... |
| [ 이전 강의 버튼 ] [ 다음 강의 버튼 ] | |

이 4가지 핵심 와이어프레임을 바탕으로 퀴즈, 과제 제출, 공지사항 등 추가적인 기능의 화면을 확장해 나갈 수 있습니다.
