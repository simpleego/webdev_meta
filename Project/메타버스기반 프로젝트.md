💬 **실시간 채팅 기능 중심 프로젝트**

1. [**webSocketChat**](https://github.com/BeomjunLee/webSocketChat)  
   - **기술**: Java, Spring Boot, STOMP, WebSocket  
   - **특징**: 채팅방별 실시간 메시지 송수신, Redis 연동으로 채팅 로그 저장  
   - **구성**: `@MessageMapping`, `@SendTo` 기반 메시지 브로커 설정

2. [**JavaSpringChat**](https://github.com/Dorosiya/JavaSpringChat)  
   - **기술**: Spring Boot 3.2.7, Spring Security, JWT  
   - **특징**: 로그인 후 유저 간 실시간 채팅 가능, 채팅방/메시지 관리  
   - **추가**: QueryDSL, MySQL, Thymeleaf 기반 UI 포함

3. [**websocket_chat**](https://github.com/pparkjs/websocket_chat)  
   - **기술**: Java, Spring Framework  
   - **특징**: 실시간 스터디 채팅 + 알림 기능 구현, 읽음 처리까지 포함  
   - **구성**: 채팅방별 메시지 관리, 알림 테이블 연동

🧍‍♂️ **아바타 관리 기능 중심 프로젝트**

4. [**Vata-BE**](https://github.com/opensource-sw-5/Vata-BE)  
   - **기술**: Java 17, Spring Boot 3.x, JPA, Minio, Stability AI API  
   - **특징**: 사용자의 성격/MBTI 기반 AI 아바타 이미지 생성 및 저장  
   - **구성**: 프로필 생성, 이미지 저장, 크레딧 관리, Swagger 문서화

🏙️ **3D 공간 구현 중심 프로젝트**

5. [**MetaAuction**](https://github.com/syi0808/MetaAuction)  
   - **기술**: TypeScript, Three.js, Cannon.js (프론트), Java 백엔드 연동 가능  
   - **특징**: 3D 공간에서 중고 물품 경매, 사용자 아바타 이동 가능  
   - **활용**: 자바 기반 서버와 연동하여 메타버스 기능 확장 가능

6. [**Incheon XR Metaverse SDK**](https://github.com/boosilguy/Metaverse)  
   - **기술**: Unity, C#, GeoJSON, FFmpeg  
   - **특징**: 인천 지역 기반 XR 메타버스 구현, 실내외 위치 서비스 포함  
   - **활용**: 자바 서버와 연계하여 백엔드 기능 확장 가능
