# LMS 프로젝트 요구사항 명세서 (보완판)

## 1. 프로젝트 개요

- **프로젝트명**: 청년들을 위한 작물 재배 교육 LMS
- **목표 및 목적**: 귀농 및 중소규모의 밭에서 농사를 시작하려는 청년들에게 농사의 기초 및 재배 교육을 효과적으로 제공하기 위함.

## 2. 사용자 요구사항

| 번호 | 기능명 | 설명 |
|------|--------|------|
| 1 | 본인 정보 조회 | 사용자 개인 정보 확인 |
| 2 | 정보 수정 | 닉네임, 비밀번호 재설정 가능 |
| 3 | 회원 탈퇴 | 계정 삭제 |
| 4 | 강의 관리 | 구독한 강의 관리 |
| 5 | 맛글 관리 | 작성한 맛글 관리 |

## 2-2. 메인페이지 기능

| 번호 | 기능명 | 설명 |
|------|--------|------|
| 1 | 강의 | 강의 수강 가능 |
| 2 | 공지사항 | 공지사항 열람 가능 |
| 3 | 채팅 | 실시간 쌍방 채팅 기능 |
| 4 | AI | AI 작물 추천 및 병충해 진단 |
| 5 | 게임 | 주제 관련 게임 진행 가능 |

## 3. 강사 요구사항

| 번호 | 기능명 | 설명 |
|------|--------|------|

| 4 | 강의 관리 | 본인 강의 등록, 수정, 삭제, 수강생 진도율, 퀴즈 여부 확인 |
| 5 | 맛글 관리 | 본인이 작성한 답글 수정, 삭제 |

## 4. 관리자 요구사항

| 번호 | 기능명 | 설명 |
|------|--------|------|
| 1 | 회원관리 | 회원 삭제 및 권한 구분 |
| 2 | 공지사항 관리 | 공지사항 등록, 수정, 삭제 |
| 3 | 맛글 관리 | 전 회원 맛글 삭제 권한 |

## 5. 비기능적 요구사항 (보완)

| 항목 | 설명 |
|------|------|
| **보안** | - 사용자 정보 암호화 저장<br>- HTTPS 통신 적용<br>- 세션 기반 인증<br>- 역할 기반 접근 제어(RBAC) |
| **성능** | - 페이지 로딩 시간 3초 이내<br>- 동시 사용자 1,000명 지원<br>- 데이터베이스 쿼리 응답 시간 1초 이내 |
| **사용성** | - 직관적인 UI/UX 제공<br>- WCAG 2.1 기준 접근성 준수<br>- 모바일 반응형 웹 지원 |
| **유지보수성** | - 관리자 페이지에서 컨텐츠 수정 가능<br>- 모듈화된 코드 구조<br>- 상세한 로깅 시스템 |
| **호환성** | - Chrome, Safari, Edge, Firefox 최신 2버전 지원<br>- iOS/Android 모바일 브라우저 지원 |

## 6. 시스템 흐름 요약

- **사용자 흐름**: 로그인 → 강의 탐색 → 강의 구매 → 학습 → 퀴즈 참여 → 게임
- **강사 흐름**: 강사 로그인 → 강의 등록/수정 → 퀴즈 등록/수정 → 수강생 학습 관리
- **관리자 흐름**: 관리자 로그인 → 컨텐츠 및 유저 관리 → 시스템 유지보수

## 7. 용어 정의 (보완)

| 용어 | 정의 |
|------|------|
| **퀴즈** | 각 강의가 끝날 시 학습 여부를 판단하기 위한 간단한 퀴즈 (5문제 4지선다), 4문제 정답 시 통과 |
| **맛글** | 각 강의 상세 게시판에 사용자들은 강의에 대한 질문사항을 맛글로 남길 수 있으며, 강사는 이를 보고 답글을 작성할 수 있음 |
| **AI** | 사용자 환경 입력 시 맞는 작물 추천 기능과 병충해 판독 기능 제공<br>- 입력: 토양, 기후, 공간 크기 등<br>- 출력: 추천 작물 목록, 재배 팁 |
| **게임** | 작물 재배 연관 게임, 강의 수강 시 게임 이용 가능, 게임 클리어 시 강의 구독 10% 할인권 지급 (중복 사용 불가, 30일 유효기간) |
| **채팅** | 실시간 채팅 기능, 채팅방 자유 입장/퇴장, 파일 공유 가능, 채팅 기록 6개월 보관 |

## 8. 기술 스택

### 백엔드 (Backend)
- 프레임워크: Spring Boot
- 언어: Java
- 데이터 접근: JDBC Template
- 웹서버: Embedded Tomcat
- 빌드 도구: Gradle
- 세션 관리: HttpSession

### 프론트엔드 (Frontend)
- 템플릿 엔진: Thymeleaf
- HTML/CSS/JavaScript

### 데이터베이스 (Database)
- DBMS: MySQL 8.0
- 백업: 주기적 자동 백업 (일일)

### 파일 처리
- 이미지 업로드: MultipartFile

### 게임제작
- 유니티(Unity)

## 9. 추가 보완사항

### 데이터베이스 설계
- ERD 작성 필수

- 인덱스 설계로 성능 최적화

### 테스트 및 배포
- 단위테스트: JUnit 5
- 통합테스트: Selenium
