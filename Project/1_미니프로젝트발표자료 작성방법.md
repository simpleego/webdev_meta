# 미니프로젝트 발표자료 가이드

### 🧭 1. 프로젝트 개요
- **프로젝트 이름**: 간단하고 기억하기 쉬운 이름
- **목적**: 왜 만들었는지 (예: 사용자 편의를 위한 웹 앱, 학습용 등)
- **사용자 대상**: 누구를 위한 서비스인지

---

### 🛠️ 2. 사용 기술
- HTML / CSS / JavaScript
- 추가로 사용한 라이브러리나 프레임워크 (예: Bootstrap, jQuery 등)
- 협업 도구 (예: GitHub, Figma 등)

> *비전공자 발표에서는 기술 설명은 간단하게, “이런 도구를 사용해봤다” 정도로만 언급해도 충분해요.*

---

### 🎨 3. 주요 기능 소개
- 핵심 기능 2~3가지만 간단히 설명
  - 예: 로그인 기능, 게시글 작성, 반응형 디자인
- 기능별 화면 캡처 또는 데모 영상 (가능하면)

---

### 📱 4. 화면 구성
- 주요 페이지 레이아웃 소개
  - 홈 화면
  - 기능별 화면 (예: 게시판, 마이페이지 등)
- 디자인 포인트 (색상, 폰트, 사용자 편의성 등)

---

### 🔍 5. 개발 과정에서의 배움
- 어려웠던 점과 해결 방법
- 새롭게 배운 개념이나 기술
- 협업하면서 느낀 점

---

### 🚀 6. 마무리 및 소감
- 프로젝트를 통해 얻은 경험
- 다음에 도전하고 싶은 것
- 팀원에게 감사 인사 (있다면)
