## 🎮 2. Unity → Spring Boot 연동

🔗 **2.1. Unity에서 HTTP 요청 보내기 (C# 스크립트)**

```csharp
using UnityEngine;
using UnityEngine.Networking;
using System.Collections;

public class CoffeeClient : MonoBehaviour
{
    public IEnumerator OrderCoffee(string coffeeType, string userId)
    {
        string jsonData = $"{{\"coffeeType\":\"{coffeeType}\",\"userId\":\"{userId}\"}}";
        UnityWebRequest request = UnityWebRequest.Put("http://localhost:8080/api/coffee/order", jsonData);
        request.method = UnityWebRequest.kHttpVerbPOST;
        request.SetRequestHeader("Content-Type", "application/json");
        
        yield return request.SendWebRequest();

        if (request.result == UnityWebRequest.Result.Success)
            Debug.Log("✅ 커피 주문 성공!");
        else
            Debug.Log("❌ 주문 실패: " + request.error);
    }
}
```

📌 Unity에서 호출 시:
```csharp
StartCoroutine(OrderCoffee("Latte", "user123"));
```

## 🗃️ 3. 추가 확장 아이디어

💬 **WebSocket 통신**  
- 실시간 상태 전달 가능 (예: 커피 준비 완료 알림)  
- Spring Boot에서 `@EnableWebSocket` + Unity C# WebSocket 클라이언트 연동

☕ **커피 종류 데이터 API화**
- 커피 종류를 Spring에서 JSON으로 전달받아 Unity에서 렌더링하는 방식

🧍‍♂️ **사용자 행동 로깅**
- 주문 내역을 Spring DB에 저장 (JPA + H2/MySQL)

🔒 **JWT 인증 추가**
- Unity 클라이언트에서 로그인 → 토큰 발급 → API 요청에 인증 헤더 포함
