Unity에서 사용자가 음료를 선택하면 → 백엔드(Spring Boot)에서 레시피 정보를 받아오고 → 주문을 완료하면서 포인트를 적립하는 전체 흐름을 하나의 C# 스크립트로 통합해볼게요. 😎  
아래는 **단일 C# 클래스**에서 UnityWebRequest를 통해 Spring Boot API를 연동하는 예제입니다.

---

## 🎯 시나리오 흐름

1. 사용자가 UI 버튼으로 음료 선택 (`Latte`, `Americano`, 등)
2. Unity가 Spring Boot로 레시피 요청 (`GET /api/recipes/{name}`)
3. Unity에서 받은 재료 정보를 기반으로 음료 생성 애니메이션 실행
4. Spring Boot로 주문 요청 (`POST /api/points/earn`) → 포인트 적립
5. 결과를 UI에 출력

---

## 🎮 C# 통합 스크립트 예제 (`CoffeeManager.cs`)

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.Networking;
using TMPro;

public class CoffeeManager : MonoBehaviour
{
    public string backendUrl = "http://localhost:8080";  // Spring Boot URL
    public string userId = "jong123";
    public TextMeshProUGUI feedbackText;

    [System.Serializable]
    public class CoffeeRecipe
    {
        public string name;
        public int coffeeAmount;
        public int milkAmount;
        public int sugarLevel;
    }

    // 호출 시 전체 흐름 실행
    public void SelectCoffee(string coffeeType)
    {
        StartCoroutine(ProcessCoffeeOrder(coffeeType));
    }

    IEnumerator ProcessCoffeeOrder(string coffeeType)
    {
        // 1. 레시피 받아오기
        UnityWebRequest recipeRequest = UnityWebRequest.Get($"{backendUrl}/api/recipes/{coffeeType}");
        yield return recipeRequest.SendWebRequest();

        if (recipeRequest.result != UnityWebRequest.Result.Success)
        {
            feedbackText.text = $"❌ 레시피 오류: {recipeRequest.error}";
            yield break;
        }

        CoffeeRecipe recipe = JsonUtility.FromJson<CoffeeRecipe>(recipeRequest.downloadHandler.text);
        feedbackText.text = $"☕ '{recipe.name}' 준비 중... 커피:{recipe.coffeeAmount}ml, 우유:{recipe.milkAmount}ml, 당도:{recipe.sugarLevel}";

        // 2. Unity 애니메이션 실행 (간단하게 딜레이 표현)
        yield return new WaitForSeconds(2f);

        // 3. 포인트 적립 API 호출
        string pointApi = $"{backendUrl}/api/points/earn?userId={userId}&amount=100";
        UnityWebRequest pointRequest = UnityWebRequest.Post(pointApi, "");
        yield return pointRequest.SendWebRequest();

        if (pointRequest.result == UnityWebRequest.Result.Success)
        {
            feedbackText.text += "\n✅ 주문 완료! 포인트가 적립되었습니다.";
        }
        else
        {
            feedbackText.text += "\n❌ 포인트 적립 실패: " + pointRequest.error;
        }
    }
}
```

---

## 🖱️ Unity UI 연결 방법

1. 버튼 객체에 `OnClick()` 이벤트 추가
2. `CoffeeManager.SelectCoffee("Latte")` 등으로 연결
3. TextMeshPro로 결과 출력 (`feedbackText`)

---

## 📌 확장 팁

- `coffeeAmount`, `milkAmount`, `sugarLevel`을 기반으로 커피 색상이나 잔 모양을 변경하는 기능 추가 가능
- 포인트 잔액 조회 및 UI 표시 기능은 `GET /api/points/balance/{userId}`로 확장 가능
- `animation.Play("Drink")` 등으로 실제 마시는 동작 추가 가능
