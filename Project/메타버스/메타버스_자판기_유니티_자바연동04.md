## 🏆 1단계: 등급 시스템 (Level System)

### 🎯 목적
- 사용자의 누적 포인트에 따라 등급을 부여 (예: Bronze, Silver, Gold)
- 등급에 따라 할인율, 특별 음료 제공 등 혜택 적용

### 🧩 Spring Boot 구현

```java
public enum UserGrade {
    BRONZE, SILVER, GOLD, PLATINUM
}

@Entity
public class User {
    @Id
    private String id;
    private int points;
    @Enumerated(EnumType.STRING)
    private UserGrade grade;
}
```

```java
public UserGrade calculateGrade(int points) {
    if (points >= 1000) return UserGrade.PLATINUM;
    else if (points >= 500) return UserGrade.GOLD;
    else if (points >= 200) return UserGrade.SILVER;
    else return UserGrade.BRONZE;
}
```

- 포인트 적립 시 등급 자동 갱신
- Unity에서 등급에 따라 UI 색상, 음료 옵션 변경 가능

### 🎯 목적
- 아바타의 외형을 사용자가 직접 설정 (헤어, 의상, 액세서리 등)
- Unity에서 시각적으로 표현, Spring에서 저장

### 🧩 Spring Boot 구조

```java
@Entity
public class AvatarProfile {

```

## 🤖 3단계: 추천 기능 (AI 기반 또는 규칙 기반)

### 🎯 목적
- 사용자의 음료 구매 이력, 등급, 시간대 등을 기반으로 음료 추천
- Unity에서 “오늘의 추천” UI로 표시

### 🧩 Spring Boot 추천 로직 예시

```java
public String recommendDrink(String userId) {
    // 최근 구매 이력 기반 추천
    List<String> history = orderRepo.findRecentDrinks(userId);
    if (history.contains("Latte")) return "Mocha";
    else return "Americano";
}
```

### 🔗 API 예시

```http
GET /api/recommend/{userId}
→ Response: { "recommended": "Mocha" }
```

### 🎮 Unity UI

- 추천 음료를 UI에 표시
- 버튼 클릭 시 자동 주문 가능

```csharp
feedbackText.text = $"오늘의 추천: {recommendedDrink}";
```
