## 🧪 기능별 확장 방법

### 🍵 1. 음료 레시피 기능
- **Spring Boot**에서 음료 종류별 레시피를 DB에 저장 (예: 커피, 물, 설탕 비율)
- Unity에서 사용자가 선택한 음료에 따라 API 호출 → 레시피 기반 제조 애니메이션 실행
- 예시 엔드포인트:
  ```java
  GET /api/recipe/{drinkType}
  ```

### 🎁 2. 포인트 적립 시스템
- 음료 구매 시 포인트 적립 (예: 1잔당 100포인트)
- Spring Boot에서 사용자별 포인트 관리 (적립/사용/조회)
- JWT 기반 인증 추가 시 사용자별 포인트 보안 강화
- 예시 엔드포인트:
  ```java
  POST /api/point/earn
  GET /api/point/balance
  ```

### 🧍‍♂️ 3. 아바타 연동 (Unity)
- Unity에서 사용자 아바타 생성 및 커스터마이징
- 커피 자판기 접근 시 아바타 애니메이션 실행 (걷기 → 주문 → 마시기)
- Spring Boot에서 아바타 정보 저장 (헤어, 의상, 포즈 등)
- 예시 구조:
  ```json
  {
    "userId": "jong123",
    "avatar": {
      "hair": "short",
      "outfit": "barista",
      "pose": "drink"
    }
  }
  ```

## 🚀 통합 구조 예시

```plaintext
Unity (UI/3D) ↔ REST API ↔ Spring Boot (비즈니스 로직) ↔ DB (레시피, 포인트, 아바타)
```

- Unity에서 버튼 클릭 → API 호출
- Spring Boot에서 로직 처리 → 응답 반환
- Unity에서 애니메이션/상호작용 실행
